# Edit your App

# Edit a public app listing
This guide explains how to update the App and Service Store listing for an existing **public app** in TikTok Shop Partner Center, including where to edit the listing, which fields affect the store page, and what happens after you submit changes for review.
This page applies to **public app listing edits only**. Custom apps are not listed publicly in the App and Service Store, so the listing sections described here do not apply to most custom apps. To edit a custom app's basic configuration, use **Partner Center > App & Service > select the app**. To understand the difference between public and custom apps, see [Create your App](https://partner.tiktokshop.com/docv2/page/create-your-app) and [App launch overview](https://partner.tiktokshop.com/docv2/page/app-launch-overview).
# Before you edit
Confirm the following before creating a new listing draft:
| Check | Why it matters |
| --- | --- |
| You are editing the correct public app | Listing changes affect what sellers see in the App and Service Store after approval. |
| The app has an existing listing draft or published listing | This guide covers editing an existing listing, not the initial public app listing submission. For first-time listing, see [Publish and list a public app](https://partner.tiktokshop.com/docv2/page/publish-and-list-public-app). |
| Brand assets and screenshots are ready | Logo, media, and screenshots must meet the file type, size, and dimension requirements shown in Partner Center. |
| Support and legal URLs are public | Do not use internal Lark, Feishu, Google Drive, intranet, or permission-gated links in a public app listing. |
| Pricing information is confirmed | If the listing displays price tags or pricing details, prepare the content before submission. See [App price information](https://partner.tiktokshop.com/docv2/page/app-price-information). |
# Open the listing draft
Use the following entry path as the standard path for editing a public app listing:
```Plain Text
Partner Center
  -> App & Service
  -> Select the public app
  -> More options (...)
  -> Listing Review
  -> Edit Draft
```

Some related pages may refer to this area as **Edit next to Publish** or **service listing review**. Use the entry that opens the **Listing Review** draft editor for the selected public app.
To edit the listing:

1. Sign in to the correct Partner Center for the app's market.
2. Open **App & Service** from the navigation panel.
3. Select the public app you want to update.
4. Open the more options menu, shown as **...**, and select **Listing Review**.
5. Select **Edit Draft**.
6. Update the listing fields.
7. Select **Save** to save draft progress.
8. When the listing is ready, select **Publish Changes**.

Draft changes are not visible in the App and Service Store until the listing review is approved.
# Listing fields
The listing editor controls how the app appears in the App and Service Store. Use the field requirements shown in Partner Center as the source of truth because requirements may vary by market, language, category, or media type.
| Listing area | Where it appears | What to prepare |
| --- | --- | --- |
| App name | Store listing title, search results, and app detail page | Use the app's public brand or product name. Keep it consistent with your support site, privacy notice, and seller-facing materials. |
| Logo | Store card and app detail page | Upload a clear square logo. Common public listing constraints include **1:1 aspect ratio** and **maximum 10 MB**. Use Partner Center validation for the current accepted file types and dimensions. |
| Short description | Store card, search results, and top of the app detail page | Summarize the app's seller value in one short sentence. Common public listing constraints include **maximum 200 characters**. |
| Featured media and images | App detail page media gallery | Use screenshots or media that show the seller-facing product experience. Do not upload internal admin screenshots, confidential dashboards, unreadable UI captures, or placeholder images. Follow the size, file type, and dimension requirements shown in Partner Center. |
| Key benefits | App detail page benefit section | Describe concrete seller outcomes, such as faster order processing, inventory synchronization, or simplified reporting. Avoid unsupported performance claims. |
| Detailed description | App detail page body | Explain the app's main use cases, supported markets, prerequisites, operational limits, and any seller actions required after installation. |
| Integrations | App detail page and store filters where applicable | List the external systems, commerce platforms, ERP, OMS, WMS, 3PL, feed tools, or other platforms the app connects with. For Connector and Multi-Channel apps, this information may associate the app with relevant **Popular platforms** filters. |
| Contact information | Support area on the app detail page | Provide a monitored support email, support site, or contact form. Avoid personal-only contact details that may become inactive. |
| Additional resources | App detail page resource links | Link to public help center pages, onboarding guides, terms, privacy notice, or API setup instructions. Do not link to internal Feishu/Lark documents or permission-gated files. |
| Price tag and price information | Pricing area on the app detail page | Select the price tag that matches the seller-facing pricing model and provide accurate pricing details. See [App price information](https://partner.tiktokshop.com/docv2/page/app-price-information). |
# Public link requirements
All links in the app listing must be accessible to external sellers and TikTok Shop reviewers without internal employee permissions.
Do not use:

* Company-internal Lark or Feishu document links.
* Internal wiki, intranet, or drive links.
* Private files that require reviewer access approval.
* Temporary file-sharing links that may expire.

Use public product, support, documentation, privacy, terms, and pricing pages instead. For pricing guidance, link to [App price information](https://partner.tiktokshop.com/docv2/page/app-price-information), not an internal document.
# Submit changes for review
When you select **Publish Changes**, Partner Center creates a listing review request.
| Review state | What it means | What to do |
| --- | --- | --- |
| Draft | Changes are saved but not submitted. | Continue editing or select **Publish Changes** when ready. |
| In review | TikTok Shop is reviewing the listing update. | Monitor the status in **Listing Review**. Do not assume draft changes are live while the request is in review. |
| Approved | The listing update passed review. | Approved listing changes become visible in the App and Service Store. Existing app authorizations are not changed by a listing text or media update. |
| Rejected | The listing update did not pass review. | Open the review details, read the rejection reason, update the draft, save it, and select **Publish Changes** again. |
Review time can vary by market, app category, language, submission quality, and whether the change also triggers app review, compliance review, or legal review. Use the status and any SLA shown in Partner Center as the source of truth. Plan for 7-10 business days for listing review, and allow longer if the update depends on broader app or compliance review.
For review workflow, review materials, and rejection handling, see [App review process](https://partner.tiktokshop.com/docv2/page/app-review-process). If the rejection reason is unclear, submit a Partner Center support ticket with the app key, service ID, target market, review status, rejection message, and screenshots. See [How to contact support](https://partner.tiktokshop.com/docv2/page/how-to-contact-support).
# How listing edits affect the App and Service Store
Use this mapping to check whether each edit changes the intended part of the public listing:
| Edit | Store effect |
| --- | --- |
| App name, logo, and short description | Updates the store card, search result appearance, and top section of the detail page after approval. |
| Featured media and images | Updates the media gallery on the detail page after approval. |
| Key benefits | Updates the benefit summary shown to sellers evaluating the app. |
| Detailed description | Updates the main explanatory content on the app detail page. |
| Integrations | Updates the integration information shown on the detail page and may affect relevant platform filters for Connector or Multi-Channel apps. |
| Contact information and additional resources | Updates seller support and onboarding links. |
| Price tag and price information | Updates how pricing is displayed to sellers, subject to the options available in Partner Center. |
