# 机构访问直播管理器

# 简介：什么是机构访问直播管理器？
为简化机构的直播运营流程，机构访问直播管理器允许TikTok Shop机构代表已绑定的达人访问PC直播管理器（[https://shop.tiktok.com/streamer)](https://shop.tiktok.com/streamer)）。
请注意：此功能目前处于测试阶段，仅对白名单合作伙伴开放。

# 有什么好处？

1. **简化运营：**通过一键登录PC直播管理器，简化机构的直播运营流程。
2. **机构赋能：**允许TikTok Shop机构代表已绑定的达人管理直播活动，增强控制和协调能力。
3. **集中管理：**为CAP提供集中页面管理所有直播活动，提高直播管理的效率和效果。

CAP发起请求后，达人将通过**EC中心 -> 系统通知 -> 合作管理**收到申请。达人可以选择接受或拒绝：

# 注意事项

1. 机构创建的任何活动将通过EC中心通知 -> 合作关系和达人收件箱 -> 系统通知 -> 账号更新传达给达人
2. CAP无法在**直播管理器上发起或结束直播**。他们只能加入达人已开始的直播，在直播期间提供支持和管理。
3. 对于跨境CAP，此功能仅适用于与CAP存在佣金分配或数据分享关系的达人。


# 常见问题
### 1. 达人能否在保持绑定的同时取消直播管理器授权？
可以，如果达人只想取消直播管理器授权而不影响现有绑定关系，解决方案是CAP和达人先解除绑定，然后CAP可以发送绑定请求**而不请求直播管理器访问权限**（在发送绑定请求时取消勾选直播管理器复选框）。

### 2. 机构在直播管理器上的活动是否会通知达人？
是的，当机构安排新的直播活动或以工作人员身份进入直播间时，达人将收到通知。

### 3. 机构在幕后进行的活动是否显示为达人的活动？
是的，直播间观众无法区分机构和达人的活动，因为机构所有操作都是通过达人账号下的直播管理器进行的。如果您发现机构有可能损害您利益的可疑活动，请联系您的CAP或客户支持进行调查。

### 4. 为什么我无法请求直播管理器访问权限？
请检查是否有待处理的绑定延期请求。在绑定延期请求待处理时无法请求直播管理器访问权限，反之亦然。
