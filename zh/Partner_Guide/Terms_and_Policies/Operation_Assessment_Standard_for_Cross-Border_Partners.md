# 跨境合作伙伴运营考核标准

|  |  |
| --- | --- |
| **类型** | **考核标准** |
| TSP | 自TSP入驻第31天起，合作伙伴须满足以下**月度**要求：<br/>  <br/> * 在与卖家关联的一个账号下完成至少10场有效直播，或在与卖家关联的一个官方账号下发布至少10条有效电商短视频，且<br/>  <br/> * 所有关联账号的总GMV大于0。<br/>  <br/> 相关定义：<br/> * 有效直播：<br/>  <br/> 1）直播为电商相关，带有黄色购物车，且商品已上传至TikTok Shop；<br/>  <br/> 2）直播时长超过1.5小时，包含超过6个商品；<br/>  <br/> 3）主播需展示商品并引导客户下单。<br/>  <br/> * 有效电商短视频：内容符合平台规则。<br/>  <br/> *如合作伙伴未满足上述任何要求，将被从TTSPC中移除，合作伙伴可在60天后重新申请。但如果再次未通过考核，同一主体将不得再次申请。 |
| MCN | * 考核方式：<br/>  <br/> * 机构后台绑定账号数 > 3（注：账号数为机构实际运营的自孵化账号个人审批通过数，违规绑定视为违反平台规则，不计入有效绑定账号数据）；<br/>  <br/> * 机构后台绑定账号考核周期GMV > 0美元；<br/>  <br/> * 无违反平台规则（录播、盗播）及其他地下产业行为；<br/>  <br/> * 以上三类考核的关系为"或"，即其中一项不满足考核标准，即视为机构通过考核。<br/>  <br/> * 未满足考核要求的机构可在60天后重新申请。如果因考核不达标再次被清退，同一主体将不得再次申请入驻。 |
| Affiliate 合作伙伴（联盟合作伙伴） | * 考核对象：<br/>  <br/> 获得TAP资格超过90天的合作伙伴可参加考核。获得TAP资格不足90天的合作伙伴（包括新TAP和重新注册的合作伙伴）不可参加考核。<br/>  <br/> * 考核方式：<br/>  <br/> 每月1日，将对过去90天内已支付销售额的跨境结算GMV金额及有销售额的达人数量进行考核。<br/> 在过去90天内，若跨境结算GMV等于或超过1000美元，且有销售额的达人数量等于或超过5人，则TAP资格予以保留。若TAP未达标，将收到清退通知，系统权限将于当月15日被收回。<br/>  <br/> * 因绩效考核不合格被平台清退后，有以下规定：<br/>  <br/> * 自TAP权限被撤销之日起，30天内不得再次申请TAP系统。30天后可重新申请。<br/>  <br/> * 若绩效考核**两次**不达标，TAP权限将在第二次被永久撤销，且不得再次申请激活。 |
| Talent Scout（达人星探） | 至少上传一位在线主播 |
| Shop On-boarding Service（店铺入驻服务） | 自合作伙伴入驻后的第一个自然月起，需在每个后续自然月满足相关业绩指标要求。若合作伙伴连续两个月未达标，将被从TTSPC中移除，合作伙伴可在60天后重新申请。但如果再次未通过考核，同一主体将不得再次申请。<br/> 合作伙伴须满足以下具体要求：<br/> 1）一个自然月内，合作伙伴推荐的有效TikTok Shop卖家数量超过100；<br/> 2）一个自然月内，合作伙伴推荐的已缴纳保证金的有效TikTok Shop卖家数量超过30； |
