# TikTok Shop合作伙伴违规管理规定

# 一、概述
## 1.1 概述
本政策管理TikTok Shop Partner Center平台（"TTSPC"）的访问和使用，适用于TTSPC平台的任何用户（"合作伙伴"），包括在TTSPC上营销、广告和提供任何服务和/或产品的相关事宜。

* 在TikTok Shop服务市场创造积极的服务订阅环境；
* 为订阅服务的卖家提供可靠的订阅体验。

所有通过TikTok Shop服务市场销售服务的合作伙伴必须遵守我们的指南。
## 1.2 范围
《TikTok电商合作伙伴违规管理规定》涵盖合作伙伴在TTSPC上营销、广告和提供任何服务和/或产品的服务发布要求。
**重要提示：合作伙伴需确保** **TikTok Shop Partner Center** **上架、** **TikTok Shop** **服务市场销售和服务提供符合适用的法律法规。**
我们的指南旨在帮助合作伙伴合规。这些指南并非详尽无遗，也不构成法律建议。如果合作伙伴对其产品的法律法规有疑问，我们建议合作伙伴寻求独立法律建议。
我们的指南会定期更新。服务合作伙伴有责任定期查看本页面，以确保遵守我们最新的指南。
## 二、定义

* 合作伙伴指在TikTok Shop服务市场上销售服务和产品的任何公司、个人、用户、个人或其他实体。
* 本政策中大写的术语应具有TikTok Shop Partner Center服务条款中规定的含义。

## 三、违规积分管理

* TikTok Shop对合作伙伴的违规行为采用积分管理机制。在TikTok Shop认定合作伙伴违规后（以其绝对裁量权为准），将根据违规严重程度发放相应积分。TikTok Shop保留对任何违反TikTok Shop Partner Center使用条款的行为采取纠正措施的权利，包括但不限于移除合作伙伴及其服务。当合作伙伴的积分达到一定水平时（由TikTok自行决定），TikTok保证对合作伙伴采取纠正措施。这不影响TikTok Shop因您违反本规则或任何其他TikTok Shop条款或政策而可能拥有的任何其他权利和救济。
* 合作伙伴的初始违规积分为0分，上限为120分，在每个日历年的第180天（6月30日23:59:59 GMT+8）和最后一天（12月31日23:59:59 GMT+8）清零。
* 不同违规积分等级的执行措施如下：

|  |  |
| --- | --- |
|  <br/> **累计违规积分** |  <br/> **措施：无运营支持** |
|  <br/> 30分 |  <br/> 30天 |
|  <br/> 40分 |  <br/> 60天 |
|  <br/> 60分 |  <br/> 90天 |
|  <br/> 90分 |  <br/> 180天 |
|  <br/> 120分 |  <br/> 不再允许进入服务市场 |
|  <br/> 备注 |  <br/> 1. 如果累计积分超过90分，合作伙伴必须在收到积分通知后的服务暂停期内提供情况说明和整改报告。如未提供或不合格，平台有权继续停用该合作伙伴的所有服务。 <br/>  <br/>  <br/> 2. 单次违规被处以120分的合作伙伴将被清退并加入黑名单，其违规积分不会清零。平台保留对合作伙伴进行"黑名单"处理并在服务市场上公示的权利。 |

* 根据违规的严重程度，我们可能在必要的纠正措施之外采取额外措施。这些措施包括暂停和/或终止您对TTSPC的访问和使用，包括在TikTok Shop上广告、营销和/或提供任何服务和/或产品（在每种情况下，全部或部分）。我们可能采取的额外措施的非详尽列表如下：
1. **限制可用服务**，即合作伙伴不允许注册任何广告资源或其他推荐活动，但这不影响其在TikTok上的存在。
2. **合作伙伴终止**，即合作伙伴从服务市场中被移除，其名下所有服务被停用。其服务的所有TikTok API调用（如有）被停止；被终止的合作伙伴将被永久禁止重新进入服务市场。
3. **对合作伙伴其他账号的处理**，TikTok Shop有权根据违规严重程度对合作伙伴的其他账号施加相同处理。
4. **冻结和扣除**因合作伙伴或其网络中的其他人（如卖家或达人）的政策违规或欺诈行为所产生的佣金和费用。

## 四、合作伙伴违规行为及纠正措施
### 1. 提供的信息不合规
#### 1.1 信息伪造
**【违规行为】** 合作伙伴提供的入驻和经营文件涉及伪造信息，在审核过程中（包括但不限于入驻审核和复审）被发现或被他人举报。这些违规行为包括但不限于：

* 提供伪造的公司注册证书
* 提供虚假的公司信息
* 未提供真实有效的卖家/合作伙伴/达人身份信息
* 未与达人/卖家/企业签署真实有效的合同
* 提交入驻时需审核的其他虚假文件
* 虚假的检测结果，包括但不限于与卖家沟通换货、提前泄露检测项目、未经检测出具合格报告以及对检测结果做出承诺

**【执行措施】：**

* 每次违规处以120分

#### 1.2 信息不完整
**【违规行为】** 合作伙伴提供的入驻文件不符合TikTok Shop的要求，在审核过程中（包括但不限于入驻审核和复审）被发现或被他人举报。这些违规行为包括但不限于：

* 未提供完整的公司注册证书
* 未提供完整的业务规模信息
* 未提供TikTok Shop不时要求的商标/专利证书或其他资质文件
* 未提供TikTok Shop不时要求的卖家/合作伙伴/达人身份信息

**【执行措施】：**

* 每次违规处以30分

#### 1.3 不符合入驻标准
**【违规行为】** 合作伙伴的资质不符合平台入驻标准，在审核过程中（包括但不限于入驻审核和复审）被发现或被他人举报。这些违规行为包括但不限于：

* 在入驻标准更新后，未提供平台要求的额外文件以证明符合入驻标准
* 重复入驻：同一实体入驻同一服务商类型超过一次
* 已被其他平台清退

**【执行措施】：**

* 每次违规处以120分

#### 1.4 未及时更新经营信息
**【违规行为】** 合作伙伴在申请入驻TTSPC及在TikTok Shop服务市场经营期间，未在其经营信息发生变更后30天内更新平台信息。这些违规行为包括但不限于：

* 公司注册证书发生变更时未及时更新
* 营业地址发生变更时未及时更新

**【执行措施】**
每次违规处以30分
### 2. 不当、有害、违法或恶意行为
#### 2.1 不当利益输送
**【违规行为】任何不当、有害、违法或恶意行为，包括但不限于：**

* 合作伙伴向字节跳动员工（包括合作伙伴的股东、董事、监事、高管及在职员工）行贿，或实施违反《字节跳动商业合作伙伴行为准则》的行为
* 机构与卖家之间的既有利益关系未上报，并为其提供了便利化服务
* 合作伙伴利用贿赂、欺诈等非法手段获取运营资源和商机
* 利用TTSPC对任何第三方造成损害
   **【执行措施】：**
* 每次违规处以120分

#### 2.2 税务违规
**【违规行为】**}
* 合作伙伴拒绝向TTSPC用户（即付款方）提供或未能及时提供有效发票或收据
* 合作伙伴在使用TTSPC过程中实施或被怀疑实施逃税、税务欺诈、发票欺诈或其他税务违规行为

**【执行措施】：**

* 情节轻微的，每次违规处以30分
* 情节一般的一般，每次违规处以60分
* 情节严重的，每次违规处以120分

#### 2.3 不当得利
**【违规行为】** 以欺诈方式获取利益，损害用户或平台利益。例如：欺诈活动和误导卖家/达人、以不诚实手段获取平台激励、异常招标、差别对待卖家以获取利润并强迫其购买服务。
**【执行措施】：**

* 情节一般的，每次违规处以30分
* 情节严重的，每次违规处以60分
 * 情节特别严重的，每次违规处以120分

#### 2.4 违规开展授权业务
**【违规行为】** 合作伙伴违规开展授权业务。这些行为包括但不限于：

* 在无授权或超出授权范围的情况下自称是合作伙伴/品牌合作伙伴/区域合作伙伴/某类型合作伙伴（例如，MCN/CAP合作伙伴冒充TSP合作伙伴）
* 制作伪造许可证并用于推广或从中获利
* 在退出某类型合作伙伴后，仍使用其名称或过往案例继续招商或经营服务
* 代理商或合作伙伴冒用官方名义、伪造许可证或其他手段收取费用、建立合作、招商等
* 制作伪造/虚假许可证/文件/非官方发放许可证，并用于推广
* 未经授权转让或使用许可证
* 退出合作伙伴后，仍使用其合作伙伴许可证从事活动、宣传和推广等
* 合作伙伴在无授权或超出授权范围的情况下以平台名义或涉及平台进行产品推广等活动

**【执行措施】：**

* 情节严重的，每次违规处以60分
* 情节特别严重的，每次违规处以120分

### 3. 虚假宣传
#### 3.1 虚假宣传/夸大承诺
**【违规行为】** 合作伙伴传播含有虚假信息、歪曲事实、夸大或过度承诺的内容，或实施其他可能引起误解的行为；或合作伙伴实施或协助违反广告法的虚假宣传或其他欺骗性、误导性行为，包括但不限于：

* 将未应用的店铺/达人账号作为成功案例展示，在与卖家/达人沟通中欺诈性使用成功案例并做出无法兑现的承诺
* 在招商或运营过程中进行虚假宣传和夸大承诺
* 虚假承诺授予某些权限等
* 虚假承诺流量支持等
* 服务标题、详情页、内部弹窗、宣传横幅等空间中描述的服务功能与实际提供的服务不一致
* 进行虚假宣传和夸大描述，或对功能进行滥用承诺或过度承诺
* 代表未订阅服务的卖家进行广告宣传
* 对合作伙伴实际不具备的类目服务能力做出虚假承诺
* 合作伙伴对效果做出夸大承诺
* 使用绝对化用语宣传服务产品

**【执行措施】：**

* 情节一般的，每次违规处以20分
* 情节严重的，每次违规处以60分

### 4. 涉嫌欺诈
#### 4.1 虚假/欺诈交易
**【违规行为】** 虚假/欺诈交易，包括但不限于：

* 通过虚假交易行为滥用活动激励、合作伙伴激励等获取激励费用
* 合作伙伴帮助卖家进行虚假交易，公开收费并推广
* 合作伙伴雇佣公司使用虚假交易提升其体验分数
* 竞争对手恶意进行的虚假交易
* 达人或名人的虚假交易
* 服务市场订单的虚假交易
* 合作伙伴从事刷粉和刷单等不当牟利服务
* 利用刷单提升服务市场评分

**【执行措施】：**

* 情节一般的，每次违规处以30分
* 情节严重的，每次违规处以60分
* 情节特别严重的，每次违规处以120分

#### 4.2 欺诈
**【违规行为】** 根据TikTok的综合判断，有理由认为合作伙伴无履行合同意愿，以获取非法利益为目的，涉嫌非法获取他人财产。
**【执行措施】**
每次违规处以120分
#### 4.3 严重描述不符（SNAD）
**【违规行为】** 橱窗或直播中展示的服务与卖家实际收到的服务完全不同。
**【执行措施】：**

* 情节一般的，每次违规处以30分
* 情节严重的，每次违规处以60分
* 情节特别严重的，每次违规处以120分

### 5. 平台信息安全
#### 5.1 信息泄露
**【违规行为】** 所有合作伙伴泄露平台或其他方的信息（分享机密信息、商业敏感信息、个人数据等），包括但不限于：

* 未经授权向第三方泄露数据、未经授权将业务数据泄露给其他实体、未经平台用户授权泄露用户个人信息
* 泄露关键业务信息（GMV数据等），未经授权在公开场合分享关键业务信息
* 合作伙伴未经授权收集、展示、披露、使用或授权他人使用服务运营数据
* 合作伙伴错误地将包含不得对外传输的检测项目和标准的完整报告传输给外部
* 合作伙伴泄露未向卖家公开的商品检测项目、仓库和工厂检测标准及通过标准信息
* 合作伙伴被举报并经核实存在数据泄露行为
* 合作伙伴非法使用植入木马的第三方软件，导致业务/消费者信息泄露
* 合作伙伴的现任或前任员工被举报滥用或泄露卖家/消费者信息
* 私自开发卖家批量解密工具，导致消费者信息泄露

**【执行措施】：**

* 每次违规处以120分

#### 5.2 数据安全
**【违规行为】** 所有合作伙伴实施破坏平台数据安全的行为，包括但不限于：

* 合作伙伴收集TikTok Shop或服务市场中卖家的账号、密码或其他身份凭据
* 合作伙伴超出卖家和服务市场的授权收集数据
* 合作伙伴未经授权保存、展示、汇总、泄露、使用或授权他人使用服务运营数据
* 合作伙伴的应用包含获取和分析平台、卖家或消费者数据并造成负面影响
* 合作伙伴将其获取的用户数据不当披露给任何第三方
* 合作伙伴未按TikTok Shop的相关要求进行整改
* 平台检测到敏感API调用，但合作伙伴未如实报告
* 主观隐瞒并秘密开发批量导出功能
* 违反平台规则秘密存储明文隐私数据

**【执行措施】：**

* 每次违规处以120分

#### 5.3 应用安全违规（包括不当API）
**【违规行为】** 所有合作伙伴实施违反平台应用安全的行为，包括但不限于：

* 通过在应用中嵌入TikTok Shop账号密码登录功能获取卖家登录状态来收集数据
* 合作伙伴将高风险端口、管理API或源代码目录等敏感信息泄露给外部
* 账号权限提升和后门程序安装等主动危害系统安全的行为
* 合作伙伴的应用干扰或试图干扰开放平台的正常运行
* 合作伙伴的应用系统存在可能导致数据泄露且未及时修复的安全漏洞
* 合作伙伴的应用未根据平台的相关安全要求进行升级或修改
* 未按平台安全相关规定在指定期限内完成安全相关升级或风险整改

**【执行措施】：**

* 每次违规处以120分

#### 5.4 恶意利用平台漏洞
**【违规行为】**
所有合作伙伴恶意利用其发现的平台漏洞并故意隐瞒。
**【执行措施】：**

* 每次违规处以120分

### 6. 扰乱平台
#### 6.1 发布违禁和敏感信息
**【违规行为】** 合作伙伴威胁平台安全，使TikTok Shop面临风险。这些行为包括但不限于：

* 政治风险：涉及政治敏感、民族、军事、外交或历史人物
* 敏感话题：涉及种族、肤色、宗教等的歧视性、冒犯性言论
* 合作伙伴以侵犯第三方权利或违反法律的任何方式使用"TikTok Shop"字样

**【执行措施】**

* 每次违规处以120分

#### 6.2 不正当竞争
**【违规行为】** 合作伙伴违反竞争法或以不公平或恶意方式扰乱服务市场。这些行为包括但不限于：

* 合作伙伴诋毁他人并散布虚假信息以损害其权益
* 合作伙伴欺骗、诱导或强迫卖家仅使用其服务但不提供服务
* 合作伙伴未经同意与达人/卖家建立合作关系
* 合作伙伴试图对其他合作伙伴产生负面影响，如抄袭
* 为吸引卖家在服务市场下单，降低检测标准
* 其他不正当竞争行为

**【执行措施】**

* 情节一般的，每次违规处以30分
* 情节严重的，每次违规处以60分
* 情节特别严重的，每次违规处以120分

#### 6.3 以TikTok名义宣传
**【违规行为】** 合作伙伴使用TikTok的名称/标志。这些行为包括但不限于：

* 合作伙伴以TikTok名义进行宣传或使用TikTok的名称/标志/模板/信号
* 合作伙伴以无效官方活动/产品的名义进行宣传
* 合作伙伴冒充TikTok或其员工冒充在TikTok工作
* 合作伙伴使用平台及其关联方的名称和标志
* 合作伙伴在服务描述中使用官方或暗示官方的表述或标志

**【执行措施】**

* 情节一般的，每次违规处以30分
* 情节严重的，每次违规处以60分
* 情节特别严重的，每次违规处以120分

#### 6.4 规避平台管理
**【违规行为】** 合作伙伴有意图规避或已规避平台管理。这些行为包括但不限于：

* 合作伙伴或其员工未履行监管要求，协助或允许卖家规避平台管理
* 合作伙伴引入或未经平台授权与未经授权的质检机构合作
* 其他旨在规避平台管理的行为
