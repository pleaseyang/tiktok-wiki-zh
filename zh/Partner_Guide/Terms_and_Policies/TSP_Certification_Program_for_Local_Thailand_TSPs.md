# 泰国本地TSP认证计划

# **什么是TSP认证计划？**
TikTok Shop合作伙伴（TSP）认证计划旨在表彰和奖励提供超越市场标准的优质服务的顶级合作伙伴。
该计划于2024年第一季度在泰国本地TSP中推出。
根据该计划，为卖家提供履约和内容管理服务的TSP可以根据良好表现获得积分。每季度根据该季度的表现颁发奖项。
奖项分为两个等级——Premier（卓越级）和Certified（认证级），分别授予达到80分或50分及以上的TSP。店铺管理和内容管理将分别颁发奖项。例如，一个TSP可以在店铺管理方面获得Premier级，在内容管理方面获得Certified级。

# **奖项权益**

1. **认可**

TSP将获得经TikTok Shop团队批准后用于宣传传播的官方徽章。

2. **客户拓展**

Premier级TSP将通过卖家中心的宣传横幅获得更多曝光。

3. **运营支持**

TSP将收到每月汇总的绩效报告并获得更多运营支持。
奖项和权益在下一季度有效，例如2024年第一季度表现获得的奖项在2024年第二季度有效，之后失效，不得再用于宣传传播。

# **如何参与**
如您希望注册，请联系tts.partner.certification@bytedance.com或您的TikTok代理商合作伙伴经理。您将收到一份注册表格。
注册时，您必须在TikTok Shop上管理至少3个卖家。
对于店铺管理类别，请仅在您提供订单履约服务的情况下纳入该店铺。
对于内容管理类别，请填写绑定到每个卖家账号的所有官方/营销达人账号。
当您管理的店铺发生变化或服务类别发生变化时，您必须通过您的客户经理使用同一表格更新我们。
# **常见问题**

1. **如果我只提供内容管理服务或店铺管理服务，能否参与认证计划？**

可以，您仍然可以在内容管理或店铺管理类别下获得积分，并有资格获得该类别的奖项。

2. **如果我虚假申报管理的店铺会怎样？**

您可能会被排除在计划之外和/或丧失之前获得的任何奖项。在合作伙伴中心没有卖家与TSP之间有效授权关系记录的店铺将不计入评分。

3. **是否必须参加该计划？**

非强制，但我们鼓励所有符合条件的TSP参加该计划。

4. **如果在季度中途绑定/解绑卖家，如何反映在评分中？**

当您管理的店铺发生变化或服务类别发生变化时，请通过您的客户经理更新我们。评分将基于您在期间管理和绑定的店铺列表。

5. **违规申诉是否会反映在评分中？**

我们将每月生成评分。如果申诉成功且在生成日期前违规积分被撤销，则将反映在评分中。

6. **我将如何收到绩效更新？**

每月将通过电子邮件发送包含您绩效的汇总报告。

7. **是否可以对所获奖项提出申诉？**

所获奖项为最终决定，由TikTok Shop自行决定。如您有任何问题或建议，请联系您的客户经理以获得进一步支持。

8. **如果一个卖家与多个代理商合作，评分如何计算？**

评分将归属于在表格中注册该卖家/账号的代理商，与系统中的绑定数据一致。每个代理商一次只能获得一个卖家/账号的评分。
