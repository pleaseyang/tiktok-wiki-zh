# TSP Access 功能

# **背景**
TikTok Shop 合作伙伴（TSP）是专注于卖家服务的电商服务提供商（店铺管理、直播管理、短视频管理、卖家联盟管理）。他们通常需要登录卖家中心以帮助卖家进行日常活动。然而，目前存在一些重大挑战。例如，TSP在代表卖家执行操作时面临需要管理多个子账号的不便。
为简化TSP请求和登录卖家中心的流程，我们提供TSP Access功能，让TSP可以一键登录卖家中心并开始运营。此外，TSP还可以通过TSP Access下的达人 IM发起和管理与达人的对话，促进代表卖家的联盟合作。
## 可用市场
美国、英国、欧洲（德国/爱尔兰/法国/意大利/西班牙）、印尼、马来西亚、越南、新加坡、菲律宾、泰国
此功能仅适用于L2L合作伙伴，不包括跨境（CB）
## 优势

1. **简化卖家中心访问请求**

TSP可以轻松与卖家分享卖家中心访问请求，并以最少的操作获得授权。

2. **无忧登录卖家中心**

TSP只需在Partner Center点击一下即可顺畅登录卖家中心，无需创建新账号。

3. **集中管理卖家账号**

TSP现在可以在Partner Center的单一位置管理所有卖家账号访问入口，并在账号之间无缝切换。

4. **通过达人 IM实现无缝达人关系管理**

TSP现在可以使用达人 IM代表卖家与达人沟通，确保他们能够全面支持联盟增长策略。同时，达人不会感知到TSP和卖家身份的区别。

# 分步指南
## 步骤1 获取卖家的TSP Access授权
卖家可以通过TSP门户或TSP发送的授权请求来授权TSP Access。
请注意：

1. 卖家必须已授权其店铺的服务，才能授予TSP Access。
2. TSP Access只能添加到当前有效的服务中。
3. 只有卖家的主账号有权授权TSP服务。
4. 在授权过程中，卖家可以选择跳过添加TSP Access。


#####
### **选项1：在授权服务类目时允许TSP Access**
#### **新授权**
在开始授权之前，TSP需要发布服务并与卖家分享授权链接。
不同市场的界面略有不同。详情请参考[获取服务授权步骤](https://partner.tiktokshop.com/docv2/page/64f198a9dc7f3e028d38171a#Back%20To%20Top) - 步骤1+2+3。此处以美国为例。

当卖家通过授权链接授权TSP服务时，卖家可以查看所有可用的未授权公共服务（属于该合作伙伴），卖家可以一次性选择多个服务进行授权。

卖家可以选择以下项目进行授权
*注意：授权将根据不同的服务资质显示，以下为示例。*

1. **授权对象：** 可以是Shop&TikTok、Shop、TikTok账号
2. **店铺工单：** 授权后，TSP可以代表您的店铺在Partner Center-工单页面发起工单
3. **卖家中心访问：** 授权后，TSP可以在卖家中心访问特定的授权页面
4. **数据罗盘：** 授权后，TSP可以根据授权查看相关数据

在此阶段，选择"卖家中心访问"以允许TSP通过卖家中心使用达人 IM。

### **选项2：通过TSP发送的授权链接授权TSP Access**
TSP还可以在Partner Center> 管理授权页面复制授权链接并发送给卖家。卖家可以打开链接完成TSP Access授权。

## **步骤2 TSP登录卖家中心并**访问所有功能
卖家完成卖家中心的TSP Access授权后，TSP可以在管理授权页面一键登录卖家中心-TSP Access登录。TSP将能够在授权的权限角色内访问所有卖家中心功能并提供进一步的运营支持。

# 常见问题
**Q1：我能同时使用卖家中心的子账号和TSP Access吗？**
在同一个Chrome配置文件中，您只能使用TSP Access或卖家中心子账号，这意味着如果您想切换到另一个，必须先退出当前账号。
