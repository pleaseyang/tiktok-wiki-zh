# [MY] TSP 服务报告

# **概述**
为了更好地衡量 TSP 对商家的实际贡献，平台现已支持 TSP 上传服务信息至平台。您的客户经理将能够查看您的服务信息并进一步核实绩效。

### 步骤 3 查看审核状态
上传服务报告相关信息后，TSP 可以前往 **[服务报告]** 页面查看审核状态并管理报告，包括查看详情、下载报告文件、删除和重新上传。
请注意

1. 仅处于待审核状态的服务报告可以删除。
2. 服务报告进入审批状态后将无法编辑

#### 审批状态
| 状态 | 描述 |
| --- | --- |
| 草稿 | TSP 创建了服务报告但尚未提交。 <br/> 此状态下 TSP 可以编辑和修改服务报告文件和信息。 |
| 待审核 | TSP 提交报告后，服务报告状态变为**待审核**，等待 TSP 客户经理审批。 |
| 已通过 | TSP 客户经理审核并同意服务报告条款，服务报告状态更新为**已通过**。此时服务报告不可编辑。 |
| 已拒绝 | TSP 客户经理审核后拒绝服务报告条款。通常会给出拒绝原因，TSP 可能需要根据反馈修改并重新提交服务报告。 <br/> ![Image](https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/744b2a66d52a4cd6a1b78669a41a4b25~tplv-k9wyc2ijk0-image.image) <br/>  |
| 已取消 | 服务报告在审核前或审核过程中被 TSP 取消 |
| 已完成 | 服务报告的服务期已到期或所有合同条款已履行完毕，服务报告状态更新为已完成。 |
| 已过期 | 服务报告已到达有效期截止日但未续期，因此自动更新为已过期状态。 |
| 已删除 | 服务报告被 TSP 删除 |
# 常见问题
## 问题 1：如果我不上传 TSP 服务报告，会影响我与卖家的现有授权吗？
不会，上传 TSP 服务报告并非必需，除非您已获得卖家授权。这不会影响您现有的授权。但是，这是计算您的激励和评估您在 TikTok Shop 绩效的必要条件。++有关政策的更多详情，请联系您的 TSP 客户经理。++
请注意，您不仅限于提供服务报告或合同作为服务证明；您还可以提交其他能够验证您服务的实质性材料。
## 问题 2：如果卖家取消授权或 TikTok Shop 账号被解绑，服务报告会怎样？
已上传的报告/合同信息不会受到影响。
