# TSP取消授权步骤

# 简介
此工具允许TSP请求取消服务授权。如果卖家同意取消或在72小时内未回复，授权将自动终止。
<div style="text-align: center"><img src="https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/a28510132c884f6ba112571242384862~tplv-k9wyc2ijk0-image.image" width="1280px" /></div>

# 步骤1：TSP发起取消请求
TSP可以进入 ++TikTok Shop Partner Center-> 卖家管理++ 并点击终止++ ++来发起取消授权请求。
![Image](https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/6ef558997b7f4b6d95f1e7e55dce01dc~tplv-k9wyc2ijk0-image.image)
![Image](https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/a3f7e76f37ce430c99275905d4e76050~tplv-k9wyc2ijk0-image.image)
TSP应填写取消的相关原因，并在需要时留下备注。这将使卖家更容易查看和审核。
# 步骤2：卖家查看并回复请求
TSP发起取消后，卖家可以在"我的服务"页面查看请求：

1. 如果卖家选择"同意"，授权将立即取消。
2. 如果卖家选择"拒绝"，授权将保持有效。您可以在144小时后联系卖家或重新提交请求。
3. **如果卖家在72小时内未回复，授权将自动取消。**

![Image](https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/73a9d868128f4b2687960ab6bde6296e~tplv-k9wyc2ijk0-image.image)
![Image](https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/25268a3f88b94d138431ae81e94bed2b~tplv-k9wyc2ijk0-image.image)
# 步骤3：查看取消请求状态
TSP可以在卖家管理页面查看取消状态，点击查看详细信息以查看操作记录
![Image](https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/6216d460405a4be18fa556597ed6bbbc~tplv-k9wyc2ijk0-image.image)
![Image](https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/6cb80e9bc5a34724a12291aac5fdc5df~tplv-k9wyc2ijk0-image.image)
卖家可以在"我的服务"页面查看取消记录。
<div style="text-align: center"><img src="https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/861c1c1e98a04890b9245045573d904e~tplv-k9wyc2ijk0-image.image" width="2556px" /></div>

*授权状态：
| 状态术语 | 定义 |
| --- | --- |
| 有效 | 您与合作伙伴的授权处于有效状态。 <br/> *包括已发起取消但在72小时内未批准或待审核的情况 |
| 已完成 | 您与合作伙伴的授权已过期。 |
| 授权已取消 | 您已取消与合作伙伴的授权。 |
| 取消 | 包括卖家取消授权或合作伙伴取消授权 |
| 已关闭 | 合作伙伴因违反平台政策已被移除。您与合作伙伴的授权已停用。 |
