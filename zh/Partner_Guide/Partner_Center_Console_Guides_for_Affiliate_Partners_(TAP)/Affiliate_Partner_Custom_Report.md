# 联盟合作伙伴自定义报告

本指南介绍了如何访问 Partner Center 分析部分中新的自定义报告功能。以下我们将说明如何使用此功能导出数据，以便查看参与您活动的达人和卖家的表现。
# **概述**
自定义报告是分析部分内的一个新功能，专为帮助联盟合作伙伴轻松访问和导出数据到 Excel 查看而设计。这将帮助您更好地可视化数据，并在 Excel 中进行任何必要的额外分析，最终帮助您为未来的活动制定有效的长期策略。
# **联盟合作伙伴的收益**

1. **支持数据自定义：** 自定义筛选器和维度以满足关键活动复盘需求，如获取特定活动的热门商品列表和检查跨活动的整体表现。
2. **提高效率：** 简化流程，使活动数据可以在一个地方轻松查看、导出和分析。
3. **提供增强洞察**：导出功能支持在 Excel 中进一步分析和处理数据，使您能够深入挖掘洞察，从而做出更明智的决策和战略规划。

# **自定义报告的使用场景**
## **场景1：我想知道特定活动列表的热门商品。**

* 您可以使用**维度**设置选择**时间**和**商品**，这将为您提供以下搜索结果标题：日期、商品 ID 和商品名称。
* 接下来，您可以使用**筛选器选项**添加您的日期范围和特定的**活动 ID**列表。点击搜索后，您将获得符合筛选条件的所有商品列表。您可以轻松将此文件导出到 Excel 中进一步分析数据，并筛选出跨活动表现最佳的商品。

## **场景2：我想知道3个活动的整体表现。**

* 要查看整体表现，只需在**维度**中选择**时间**（您**不需要**选择其他维度），这将在搜索结果中产生以下标题：日期、佣金、收入、订单数、直播 GMV、视频 GMV 和橱窗 GMV（这些是在未选择维度时的默认标题）。
* 您还可以使用**筛选器选项**添加日期范围并输入您感兴趣的活动的活动 ID。点击搜索后，您将获得筛选中选择的3个活动的整体表现。

## **场景3：我想知道几个活动的达人列表（按周查看）。**

* 您可以使用**维度**设置选择**周**（*一周始终从周日开始*）和**达人**，这将使搜索结果中出现以下标题：日期、达人名称和达人昵称。
* 接下来，您可以使用**筛选器选项** **添加您想查看达人的特定活动 ID**。点击搜索后，您将获得所选活动中所有达人的列表。

## **场景4：我想知道多个活动中特定店铺的商品合作进展。**

* 您可以使用**维度**设置选择**时间**、**店铺**和**商品**，这将为您提供搜索结果中的以下标题：日期、店铺 ID、店铺名称、商品 ID 和商品名称。
* 接下来，您可以使用**筛选器选项** **添加特定的店铺 ID 和活动 ID**。点击搜索后，您将获得筛选中选择的活动的所有商品和店铺列表。您可以轻松将此文件导出到 Excel 中进一步分析数据，包括进一步筛选结果以了解哪些店铺产生的畅销商品最多。

# **如何在 Partner Center 中使用自定义报告**
前往：**Partner Center > 分析 > 自定义报告**
自定义报告中有几个部分，我们将在下面详细介绍，以帮助您了解如何有效使用此功能导出数据。
注意：

1. 如果机构同时提供 TSP 或 MCN/CAP 服务以及 TAP 服务，目前他们将只能看到其 TAP 服务关联地区的自定义报告数据。
   1. 例如：如果一个机构在 MY 和 ID 都注册为 MCN/CAP，但仅在 MY 注册为联盟合作伙伴，则他们只能在 MY 地区打开自定义报告页面。
2. 自定义报告中的地区不会自动与分析部分其他标签选择的地区相同。
   1. 例如：一个机构在 MY 和 ID 都注册为 ++MCN/CAP 和联盟合作伙伴++。在视频分析标签查看数据时，他们将地区从 ID 切换为 MY。但是，当他们打开自定义报告标签时，地区将恢复为 ID，而不是与视频分析标签中查看的地区保持一致。

## **使用维度**
在维度部分，您可以选择多个不同的维度。维度对应于搜索结果中显示的标题。

1. **时间维度** — 在此处，您可以从**以下选项中选择一个。**
   1. 按天
   2. 按周（从周日开始）
   3. 按月
   4. 按整个期间（延伸到过去6个月，勾选时间维度时默认选择）

![Image](https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/9d2b7ba821de4595a5289de896131052~tplv-k9wyc2ijk0-image.image)

2. **其他维度** — 您可以**多选**以下任何选项。唯一的例外是直播和视频不能同时选择。

注意：当您选择每个维度时，**与该维度关联的所有类型**将自动选中并显示在结果中。
| **维度** | **类型** |
| --- | --- |
| 活动 | 活动 ID、活动名称、活动状态、活动验证、活动时间信息 |
| 达人 | 达人名称、达人昵称 |
| 直播 | 直播间 ID、直播名称、时间信息 |
| 视频 | 视频 ID、视频名称、发布时间 |
| 商品 | 商品 ID、商品名称 |
| 店铺 | 店铺 ID、店铺名称 |
| 商品类目 | 商品类目（1-2级） |

## **使用筛选器**
筛选器可以帮助您更好地细化搜索结果。您可以从时间筛选器以及以下类别中进行选择。

1. **时间** — 支持固定和动态时间段，最早日期选项为过去6个月。
   1. **固定日期范围：** 在日历框中选择您想要的日期范围。
   2. **动态日期范围：** 从以下选项中选择一个：
      1. 过去7天
      2. 过去28天

![Image](https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/5185e8aa3e0e4098a93e25df2db03403~tplv-k9wyc2ijk0-image.image)

2. **达人 Handle、商品 ID、店铺 ID、活动 ID 筛选器** — 这4个筛选器各自支持单次搜索和批量输入。使用批量输入时，您可以用逗号分隔每个项目，每个筛选器最多粘贴500个项目。
   1. 您可以选择是否要**包含或排除**为每个筛选器粘贴的项目。
   2. 此部分很有用，因为它允许您细化结果，使显示的数据仅针对您添加到筛选器中的项目。

## **导出数据**

1. 选择维度和筛选器后，按**搜索**获取相应结果。您将看到的搜索结果总数。

注意：如果搜索结果数大于500，则仅显示前500个结果，您可以通过翻页查看。要查看额外结果，您需要按**导出**，这将**导出所有结果**到 Excel。

要将此数据导出到 Excel，请点击右侧的**导出**图标。这将自动将**所有项目**下载到保存到您电脑的 Excel 文件中。

您还将看到**导出报告**图标，其中列出了您之前导出的报告，您可以在7天内下载（最多可显示500,000条记录）。

# **常见问题**

1. **我可以选择在搜索结果中显示所选维度的哪些对应类型吗？**

不可以，您不能选择与维度关联的单个类型。与维度关联的所有类型将自动选中并显示在结果中。
例如，如果您选择了直播维度，您的搜索结果将自动显示所有关联类型：直播间 ID、直播名称和时间信息。

2. **MCN/CAP 或 TSP 服务类目也可以使用自定义报告吗？**

目前只有联盟合作伙伴可以访问自定义报告，但我们将在未来几个月内为 MCN/CAP 推出此功能。
