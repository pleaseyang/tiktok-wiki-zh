# 合作伙伴活动 - 广告佣金

# 核心机制 
合作伙伴活动广告佣金双重归因是 TikTok Shop 合作伙伴（TSP）的新更新。这使卖家能够为合作伙伴活动中的商品设置活动总**店铺广告佣金率**，同时根据归因结果在合作伙伴和达人之间自动分配佣金。 
以下是联盟合作伙伴店铺广告的核心机制。

* 目前，联盟合作伙伴店铺广告功能在美国地区可用。
* 卖家可以在机构活动、卖家活动和 TikTok Shop 独家活动的新活动或进行中的活动中设置费率。设置后费率不可更改。
* 只有当卖家为活动中的商品设置了店铺广告佣金率时，合作伙伴才能在 Partner Center 的活动和商品池中看到此费率。
* 如果卖家为商品设置了店铺广告佣金率，当合作伙伴设置联盟佣金率时，合作伙伴和达人之间的广告佣金分配比例默认与联盟佣金相同。系统自动计算并准确显示比例至小数点后两位。 
* 如果卖家未设置 TAP 活动广告佣金率而投放广告，广告订单将按照 TAP 活动联盟佣金率进行结算。
* 联盟佣金和广告佣金的归因逻辑：本质上与公开合作相同。总之，如果联盟和广告归因于同一达人，将按广告佣金率结算；其他情况下，将按联盟佣金率结算。

# 标准佣金率 vs 店铺广告佣金率
我们为您准备了不同的场景供参考，如果您选择使用达人的内容投放视频购物广告。 
| **佣金场景** | **标准佣金率** | **店铺广告佣金率** | **达人将获得什么？** |
| --- | --- | --- | --- |
| 1. 卖家为达人的视频设置了店铺广告佣金率，买家从 FYP 中发现的**广告**中添加商品。 | 10% <br/> <!-- rowSpan:4 --> <br/> | 5% <br/> <!-- rowSpan:4 --> | **5% - 店铺广告** |
| 2. 卖家为达人的视频设置了店铺广告佣金率，买家从 FYP 中的**达人自然视频**中添加商品。 | | | **10% - 标准** |
| 3. 卖家为达人的视频设置了店铺广告佣金率，买家从**达人账号中发现的达人视频**中添加商品。 | | | **10% - 标准** |
| 4. 卖家推广达人的视频但未设置店铺广告佣金率。 | | | **10% - 标准** |
