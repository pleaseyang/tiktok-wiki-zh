# 多渠道网络（MCN）

# 什么是多渠道网络（MCN）？
多渠道网络（MCN）在 TikTok Shop 生态系统内孵化和支持达人。此类合作伙伴在多个方面支持达人，包括可购物视频内容创作、可购物直播运营以及联盟项目的达人-商品匹配。
# 成为 TikTok Shop MCN 有什么好处？
**合作机会**

* MCN 成员可以获得与知名卖家和品牌的合作机会，为创新和互利的合作伙伴关系打开大门。

**丰厚佣金**

* MCN 因其在招募、培训和孵化达人方面的贡献而获得丰厚回报。

**专业成长指导**

* 定制指导和达人培训，帮助实现快速增长

**定制服务**

* 高绩效 MCN 获得根据其独特需求和目标量身定制的专属支持。
