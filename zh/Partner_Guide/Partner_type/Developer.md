# 开发者

# 什么是开发者？
开发者利用 TikTok Shop API 构建应用，为商家提供自动化、管理和增长 TikTok Shop 业务的解决方案。
通过 TikTok Shop 合作伙伴中心，我们提供全面的技术工具、资源和 API，允许开发者直接集成 TikTok Shop。
我们的 API 涵盖商家运营的整个流程，允许开发者创建集成方案以简化商家工作流程并改善客户体验。

# 开发者类型
开发者分为三种类型：商家开发者、应用开发者和系统集成商。更多信息请参见下表。
| 开发者类型 | 定义 | 应用类型 |
| --- | --- | --- |
| 商家开发者<br/>（TikTok Shop 商家） | 商家开发者是直接将 TikTok Shop 与其系统集成的开发者。通常是那些需要定制方案来支持自身在 TikTok Shop 上运营的商家。**这是对所绑定的 TikTok Shop 商家账号的直接 1:1 授权。**（除重点商家外，您可以要求客户经理（AM）将账号添加到白名单）<br/> 商家账号在入驻前必须分配客户经理（AM）。如果未分配 AM，请联系 TikTok Shop 商家中心客服先行设置。 | 定制应用 |
| 系统集成商 | 经特定商家授权创建定制集成的技术服务提供商 | 定制应用<br/>公开应用 |
| 应用开发者 | 应用开发者是构建应用以支持商家在 TikTok Shop 上运营的开发者。 | 定制应用<br/>公开应用 |

# 成为 TikTok Shop 开发者有什么好处？
在 TikTok Shop 应用商店中构建应用或提供服务可以带来多项优势，包括：访问开发服务以使商家能够向 TikTok 庞大的用户群销售；通过一次性或订阅定价实现变现；在 TikTok Shop 商家中心获得曝光和可见度；引入 TikTok 原生功能中不具备的创新功能和特性的能力；以及长期潜力——一旦应用获得用户认可，它可以在较长时期内产生收入并为商家提供价值。
**开放开发能力**

* 全面的 API 允许开发者根据需求解决不同的业务场景，并创建超越 TikTok 原生功能的创新功能

**增长与曝光**

* 在应用和服务商店发布公开应用，在使用 TikTok Shop 商家中心的商家中获得曝光和可见度

**技术支持**

* 通过 TikTok Shop 合作伙伴中心，我们提供按需支持和快速响应，帮助在开发过程中解决您的问题

**开发者工具**

* 利用我们的沙箱、Webhook 和全面的文档更高效地开发

**激励机会**

* 通过平台支持的组合解锁盈利潜力
