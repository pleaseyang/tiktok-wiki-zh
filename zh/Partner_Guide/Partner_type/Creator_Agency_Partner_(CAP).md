# 达人机构合作伙伴（CAP）

# 什么是达人机构合作伙伴（CAP）？
达人机构合作伙伴（CAP）在 TikTok Shop 生态系统内孵化和支持达人。这些机构管理、代理或拥有美国地区的达人资源，并通过大规模招募、培训和孵化达人来制作短视频 + 直播电商内容，服务于 TikTok Shop。
# 成为 TikTok Shop CAP 有什么好处？
**合作机会**

* CAP 可以获得与知名商家和品牌的合作机会，为创新和互利的合作伙伴关系打开大门。

**丰厚的财务激励**

* CAP 因其在招募、培训和孵化达人方面的贡献而获得丰厚回报。

**专业成长指导**

* 我们的合作伙伴运营团队为 CAP 提供定制指导和全面的达人培训项目。这些资源帮助参与者实现快速增长并提升专业发展。

**CAP 合作伙伴服务：管理支持与规模化解决方案**

* 通过指定的一对一管理支持，解决机构合作伙伴的需求和目标，提供包括但不限于数据分析、战略规划和合作伙伴教育的战略价值
* 旨在赋能 CAP 机构的规模化解决方案支持。该计划旨在支持机构更加自给自足，提升其孵化、赋能和增长电商达人的能力。
