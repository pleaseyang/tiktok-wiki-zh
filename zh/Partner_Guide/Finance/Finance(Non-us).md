# 财务（非美国）

📌 **此功能仅适用于 TTSPC 上的** [MCN](650a39fe0fcef602bf26c0d3)**、**[CAP](6789f71c23ae4b030c389d61)**、**[TAP](6789f710c0833b0310f153f0) **合作伙伴**。
可用市场：英国、印尼、马来、越南、泰国、菲律宾、新加坡
## 什么是财务？
财务功能使 MCN 和 TAP 能够在与达人分成佣金后查看和导出订单和账单。
## 【收款账号】激活账号并绑定银行账户

## 【收益】查看佣金订单
您可以在**[收益]**标签下查看佣金订单
注意：
**[收益]**标签将显示**与 MCN 有佣金结算关系的达人**的所有佣金订单
<div style="text-align: center"><img src="https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/796c9afe1a36453ba2c3b9c7251bf3a0~tplv-k9wyc2ijk0-image.image" width="500px" /></div>

**步骤2 查看佣金订单**
您可以在顶部查看**佣金订单**的概览，包括

* 已支付（成功支付的订单），您可以前往[已支付]标签查看详情
* 未支付（包括待支付和支付失败的订单），您可以前往[待支付]和[支付失败]标签查看详情

<div style="text-align: center"><img src="https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/7ce974b2599643da9a0a93c2e3d9ae79~tplv-k9wyc2ijk0-image.image" width="500px" /></div>

**步骤3 查看和导出订单详情**

* 您可以在[待支付]、[已支付]和[支付失败]下查看订单详情。
* 您可以按用户名、商品 ID、订单创建时间、订单发货时间进行筛选

<div style="text-align: center"><img src="https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/3b02c63de2ef4ee885e70138b665a835~tplv-k9wyc2ijk0-image.image" width="500px" /></div>


* 点击[导出]支持全部导出或批量导出（可选择筛选条件或当前标签下的所有订单。**一次最多250000个订单**）

<div style="text-align: center"><img src="https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/ca57c7730d8e466cbf47f841215f7793~tplv-k9wyc2ijk0-image.image" width="500px" /></div>

### **收益字段说明：**
| 字段名称 | 说明 |
| --- | --- |
| 订单 ID | 主（SKU）订单 ID |
| 订单行 ID | 子（SKP）订单 ID。 <br/> 📌 注意：达人端的订单为订单行 ID |
| 达人 | 达人资料/用户名/昵称 |
| 商品 | 商品图片、名称、规格、商品 ID。 |
| 售价与数量 | 商品售价与数量 |
| 内容类型 | 包括直播、短视频和橱窗 <br/> -您可以点击直播间/短视频跳转到详情页 <br/> -下载数据后您可以查看推广 ID（即视频 ID/直播间 ID） |
| 佣金率 | 卖家设置的佣金率 |
| 佣金奖励率 | TikTok 资助的佣金奖励率 |
| 预估佣金基数 | 预估佣金基数为商品售价乘以订单创建时的商品销售数量。 <br/> 预估佣金基数 = 售价*订单数量 |
| 预估总佣金 | 预估佣金为预估佣金基数乘以佣金率的金额。 |
| 预估佣金奖励 | 预估佣金奖励为预估佣金基数乘以佣金奖励率的金额（包括退款订单）。 |
| 实际佣金基数 | 实际佣金基数为商品售价乘以实际销售数量，不包括退货和退款订单。 <br/> 实际佣金基数 = 商品价格*（订单数量 - 退款数量）（不包括退款订单） |
| 机构佣金 | 实际佣金为实际佣金基数乘以佣金率的金额 |
| 机构佣金奖励 | TikTok 支付给 MCN 的实际佣金奖励 |
| 退货与退款 | 退货与退款数量 |
| 计划 ID | 商品的计划 ID |
| 创建时间 | 订单创建时间 |
| 发货时间 | 订单确认发货时间 |
| 佣金支付时间 | 订单佣金结算到银行卡的时间 |
| 支付 ID | 支付 ID 可以帮助您将每笔订单与支付账单页面上的支付 ID 进行匹配。 <br/> **注意：如果没有支付 ID，表示该订单仍在支付进行中** |
| 支付方式 | --- |
| 支付账号 | --- |
