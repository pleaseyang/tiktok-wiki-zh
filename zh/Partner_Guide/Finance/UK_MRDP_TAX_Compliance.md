# 英国 MRDP 税务合规

## **什么是英国 MRDP 合规？**
**英国 MRDP**，即**英国数字平台模型报告规则（UK Model Reporting Rules for Digital Platforms）**，是一项税务法规，要求数字平台上的合作伙伴报告特定的税务信息。遵守英国 MRDP 可以帮助您避免处罚、收款冻结和潜在的账号停用。但请放心，我们致力于为您提供所有必要的工具和信息，帮助您轻松完成整个流程。

---


## **您需要申报吗？**
如果您作为 TikTok Shop 电商合作伙伴收到了任何佣金，您需要遵守英国 MRDP。
**提示：** 请确保您了解申报要求和截止日期。保持信息更新将帮助您顺利完成合规，避免账号出现任何问题。

## **需要哪些信息？**
以下是**英国 TTS 合作伙伴**的不同要求摘要：
| **要求** | **合作伙伴** |
| --- | --- |
| **基本信息** | - 主要地址 <br/> - 法定名称 |
| **税务识别号（TIN）** | - 需要 TIN 编号（公司注册号） |
| **增值税（VAT）ID 编号** | - 如已注册 VAT，需提供 VAT 注册编号 <br/> - 如未注册，可选择"否" |
| **附加详情** | - 需要公司注册号 |

**提示：** **准备好您的 VAT 和 TIN 文件**，以确保快速轻松地提交。

## 保持更新，保持合规
如果您作为合作伙伴获得了佣金，系统将提示您（通过邮件和通知）提交您的英国 MRDP 信息。**以下是操作指南：**

* 步骤1：登录您的 TikTok Shop Partner Center
* 步骤2：按以下路径操作：财务>税务信息>MRDP 
* 步骤3：点击更新，按照表单填写所有必要信息
* 步骤4：提交并等待验证

## **年度确认要求**

* **年度确认：** 从明年开始，合作伙伴必须在每年12月31日前确认其英国 MRDP 信息的准确性。
* **未确认的处罚：** 如果连续三年未完成确认，收款将被冻结。

**需要采取的行动：** 每年审核并确认您的英国 MRDP 信息，以保持收款不受影响。

## **英国合作伙伴清单：**

1. **确认资格：** 如果您收到了任何佣金，您需要遵守。
2. **准备文件：** 确保 TIN 和 VAT 信息已准备好提交。
3. **响应通知：** 根据提醒采取行动，避免执法措施。
4. **每年确认：** 从明年开始，在每年12月31日前审核您的英国 MRDP 详情。
5. **保持信息更新：** 关注提交和验证截止日期，确保持续获得收款权限。

根据英国数字平台模型报告规则（UK MRDP）的要求，TikTok Shop 向您提供提交给 HMRC 的信息副本。该报告包括您在报告年度内的 TikTok Shop 总收入和关键税务详情。

### 在哪里找到
进入 **Partner Center**，导航到财务标签，找到新的 **MRDP** 部分。在那里您可以：

* 选择**报告年度**
* 查看提交报告的 **TikTok Shop 实体**
* **下载报告**（Excel 格式）
* 根据需要使用的筛选器或批量下载

### 注意事项：

* 本报告仅供**参考**，反映的是 TikTok Shop 提交给 HMRC 的相同数据。
* 如果在提交时您的税务信息（如 NINO 或营业地址）缺失，这些字段在报告中可能显示为空白。
* 请咨询税务顾问以验证您的申报并确保合规。


### 报告中包含哪些内容？
| **名称** | **说明** |
| --- | --- |
| **ID** | 系统自动生成的唯一参考编号，用于在本报告中识别您 |
| **个人/实体** | 表明您是个人还是公司 |
| **居住国家代码** | 在本报告中您被视为税务居民的国家代码。如果您在欧盟，则包括：1. 签发您 TIN 的欧盟成员国 2. 您设有常设机构的成员国 3. 您的主要地址所在的任何欧盟成员国。例如，如果您的公司在爱尔兰（国家代码 IE）注册并设有主要地址，在法国（国家代码 FR）持有 TIN，在西班牙（国家代码 ES）设有常设机构，则此字段将列出"IE、FR、ES"。对于英国，您的居住国家是您主要地址所在的国家（公司）或个人或个体经营者的居住地址所在国家。 |
| **TIN** | 您的税务识别号 |
| **TIN 签发国** | 签发您 TIN 的国家代码 |
| **实体识别码** | 您公司的注册号 |
| **VAT** | 您的增值税（VAT）识别号 |
| **实体名称** | 您公司或实体的法定名称 |
| **个人姓氏** | 个人或个体经营者的姓氏 |
| **个人中间名** | 个人或个体经营者的中间名 |
| **个人名字** | 个人或个体经营者的名字 |
| **个人前缀** | 个人或个体经营者的前缀，如先生、女士或博士 |
| **出生日期** | 个人或个体经营者的出生日期 |
| **出生地国家代码** | 个人或个体经营者出生地的国家代码 |
| **常设机构** | 您常设机构的地址。这是企业持续经营并需缴纳企业所得税的场所。 |
| **地址国家代码** | 您主要地址（公司）或居住地址（个人或个体经营者）的国家代码 |
| **主要地址** | 公司的主要地址，或个人或个体经营者的居住地址 |
| **相关活动** | 产生收入的活动类型。例如，达人和合作伙伴为 PersonalServices，卖家为 SaleOfGoods。 |
| **对价** | 对价是与相关活动相关的、记入或支付给您的任何费用、佣金或扣减税款后的净额。请查看报告中的详细数据了解更多信息。 |
| **对价货币代码** | 对价金额的货币代码 |
| **预扣费用** | 对于卖家，这是 TikTok Shop 发票上显示的金额。对于达人和合作伙伴，此金额为0。 |
| **预扣费用货币代码** | 预扣费用的货币代码 |
| **税款** | 从您在 TikTok Shop 的销售或服务中预扣的税款 |
| **税款货币代码** | 预扣税款的货币代码 |
| **活动数量** | 每季度对应于对价的交易数量。请查看报告中的详细数据了解更多信息。 |

本报告反映的是 TikTok Shop 向相关税务机关提交之前您账号中可用的**日历年**数据。
