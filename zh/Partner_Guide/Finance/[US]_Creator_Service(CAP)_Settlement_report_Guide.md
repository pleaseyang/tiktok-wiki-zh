# [US] 达人服务（CAP）结算报告指南

# 什么是结算报告？
结算报告是一份财务文件，详细列出了指定结算期内您的账号活动。此报告使您能够核对所赚取的佣金。
# 如何下载结算报告？
要下载结算报告，请按以下步骤操作：
Partner Center - 财务 - 付款 - 收益 - 导出订单。
# 如何阅读结算报告？
以下是各列的定义。
| **列名** | **定义** |
| --- | --- |
| 订单 ID | 唯一订单标识符 |
| SKU ID | SKU 唯一 ID |
| SKU | SKU 名称 |
| 商品 ID | 商品唯一 ID |
| 商品名称 | 商品名称 |
| 价格 | 商品价格 |
| 数量 | 商品数量 |
| 达人用户名 | 达人用户名 |
| 标签 ID | 第三方 linkshare 达人标识符，仅对东南亚机构可见。 |
| 店铺名称 | 卖家店铺名称 |
| 店铺代码 | 卖家店铺代码 |
| 货币 | 交易货币（例如 USD、MXN）。 |
| 订单类型 | 归因订单的渠道，例如联盟或店铺广告。 |
| 订单结算状态 | 与平台的订单结算状态（例如已结算或待处理）。 |
| 内容类型 | 产生订单的内容类型，如视频、直播、橱窗。 |
| 内容 ID | 内容唯一 ID |
| 归因类型 | 归因类型，例如：直接、间接 |
| 佣金模式 | 应用于此订单的佣金模式，如基于订单量的阶梯费率或固定费率。 |
| 标准佣金率 | 应用于可佣金 GMV 的标准基础佣金率，以百分比表示。 |
| 店铺广告佣金率 | 店铺广告流量的佣金率，以百分比表示。 |
| TikTok 佣金奖励率 | TikTok 佣金奖励率，以可佣金基础的百分比表示。 |
| 合作伙伴佣金奖励率 | 合作伙伴佣金奖励率，以可佣金基础的百分比表示。 |
| GMV | 买家为订单支付的金额（GMV）。 |
| 预估佣金基数 | 结算前的预估可佣金金额，用作计算所有佣金组成部分的基础。 |
| 预估标准佣金 | 订单尚未结算时，在达人-MCN 收入分成前的预估标准佣金部分。 |
| 预估店铺广告佣金 | 订单尚未结算时，在达人-MCN 收入分成前的预估店铺广告佣金部分。 |
| 预估 TikTok 佣金奖励 | 订单尚未结算时，在达人-MCN 收入分成前的预估 TikTok 佣金奖励部分。 |
| 预估合作伙伴佣金奖励 | 订单尚未结算时，在达人-MCN 收入分成前的预估合作伙伴或机构资助的佣金奖励部分。 |
| 实际佣金基数 | 结算后的最终可佣金基础金额，用于计算实际佣金。 |
| 实际标准佣金 | 结算后，在达人-MCN 收入分成前的最终标准佣金部分。 |
| 实际店铺广告佣金 | 结算后，在达人-MCN 收入分成前的最终店铺广告佣金部分。 |
| 实际 TikTok 佣金奖励 | 结算后，在达人-MCN 收入分成前的最终 TikTok 佣金奖励部分。 |
| 实际合作伙伴佣金奖励 | 结算后，在达人-MCN 收入分成前的最终合作伙伴或机构资助的佣金奖励部分。 |
| 达人税款 | 平台代表达人预扣并支付的总税款。 |
| 分成前实际佣金收益 | 在达人-MCN 分成前，归属于达人的总佣金收益，扣除达人税款。SUM(AB+AC+AD+AE-AF) |
| 机构佣金分成部分 | 应用于达人佣金收入的合同约定 MCN 收入分成百分比。 |
| 达人实际获得佣金总额 | MCN 分成后实际支付给达人的最终佣金收入。 |
| 税前机构获得佣金总额 | 机构级税前分配给 MCN 的总佣金。 |
| 机构税 - ISR | 在墨西哥代表机构预扣并缴纳的所得税（ISR）。 |
| 机构税 - IVA | 在墨西哥代表机构预扣并缴纳的增值税（IVA）。 |
| 机构实际获得佣金总额 | 机构税后 MCN 实际收到的最终佣金收入。 |
| 外汇换算后机构实际获得佣金总额 | 应用外汇汇率后转换为结算货币的机构总佣金。 |
| 汇率 | 用于将佣金金额转换为结算货币的外汇汇率。 |
| 邀请 ID | 与达人或订单相关的邀请或招募活动的标识符。 |
| 订单创建时间 | 订单创建的时间戳。 |
| 订单发货时间 | 订单发货的时间戳（如有）。 |
| 支付 ID | 付款交易 ID（仅限成功付款）。 |
| 支付状态 | 付款状态 |
