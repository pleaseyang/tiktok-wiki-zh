# [US] 达人匹配（TAP）结算报告指南

# 什么是结算报告？
结算报告是一份财务文件，详细列出了指定结算期内您的账号活动。此报告使您能够核对所赚取的佣金。
# 如何下载结算报告？
要下载结算报告，请按以下步骤操作：
Partner Center - 财务 - 付款 - 收益 - 导出订单。
# 如何阅读结算报告？
以下是各列的定义。
| **列名** | **定义** |
| --- | --- |

| SKU ID | SKU 唯一 ID |
