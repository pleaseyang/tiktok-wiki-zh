# 合作伙伴注册申请要求

# MCN/CAP
如果您申请的是 MCN/CAP，请在业务类别中选择"达人管理"
### **通用资质信息**
通用资质信息在不同类别中保持一致。您只需在入驻时填写一次。如果您想申请新的类别，通用资质信息将自动复用，无需重新填写。对于某些企业合作伙伴，TikTok Shop 可能还会要求提供与公司最终实益所有人（UBO）相关的信息和证明文件，即最终拥有或控制公司的个人。如需额外的 UBO 信息或文件，TikTok Shop 将通过 Partner Center 通知您并提供需要提交内容的说明。
| **字段** | **格式** | **备注** |
| --- | --- | --- |
| 公司全称 | 文本 | 需与营业执照上的公司名称一致，不超过100个字符 <br/> *应与公司文件一致 |
| 注册日期 | 日期 | 年/月/日 |
| 公司注册号 | 文本 | 不超过100个字符 <br/> *应与公司文件一致 |
| 公司文件类型 | 选项 | 根据公司实体选择，参考[指引](https://bytedance.feishu.cn/docx/XkYVdMmwwoTCkjxBo56couGEnP5?from=from_copylink) |
| 公司文件 | 图片（jpg/jpeg/png） | 根据公司实体选择，参考[指引](https://bytedance.feishu.cn/docx/XkYVdMmwwoTCkjxBo56couGEnP5?from=from_copylink)，图片不超过10M |
| 国民身份证（DNI） <br/> *仅在西班牙和爱尔兰市场要求 | 上传图片并输入字符 | 1. 上传 DNI 正反面图片 <br/> 2. 名、中间名、姓 <br/> 3. 证件号码 <br/> 4. 出生日期 |
| 注册营业地址 <br/> *仅在西班牙和爱尔兰市场要求 | 输入字符 | 城市、区、郊区、城镇或村庄。 <br/> 州、县、省或地区。 <br/> *应与公司文件一致 |
| 企业所有人证件类型 | 选项 | 根据公司实体选择，参考[指引](https://bytedance.feishu.cn/docx/XkYVdMmwwoTCkjxBo56couGEnP5?from=from_copylink) |
| 企业所有人证件 | 图片（jpg/jpeg/png） | 每个模块仅支持上传1张图片，图片不超过10M |
| 合作伙伴名称 | 文本 | 合作伙伴的名称，未来将在代表合作伙伴的其他场景中展示，请妥善填写；不超过100个字符 |
| 合作伙伴Logo | 图片（jpg/jpeg/png） | 尺寸1080*1080，不超过30M |
| 营业地址 | 文本 | 公司营业地址，代表您当前的工作地址。请用英文填写，遵循以下规则：国家 + 地区 + 具体地址 + 邮政编码；不超过150个字符 |
| 机构网站/LinkedIn（可选） | 文本 | 提供您公司的官方网站/LinkedIn。 |
| 机构介绍/推介材料（可选） | 仅PDF <br/> 最大尺寸：30 MB | 上传您的公司介绍文档。 |
