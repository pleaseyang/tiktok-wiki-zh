# [UK] TikTok Shop 合作伙伴分级机制

TikTok Shop 合作伙伴（TSP）分级系统旨在培育健康的生态系统，设定服务标准，并为不同发展阶段的 TSP 提供定制化资源——从而引导其成长路径。
在分级系统中，TSP 将指所有 TSP/TAP/CAP 的整合。
*本分级机制仅适用于在英国市场认证并运营的 TikTok Shop 合作伙伴。*

# **合作伙伴等级更新**

* 原有的 TSP、CAP 和 TAP 合作伙伴将统一归入一个名称：***TikTok Shop 合作伙伴（TSP）***，分为 **两种主要服务类型：** **卖家服务** 和 **达人服务**。

* ++卖家合作伙伴++ **** （前身为 TSP）
   * 卖家合作伙伴的主要功能是通过店铺运营管理、短视频制作管理、联盟视频管理和直播管理为 TikTok Shop 上的卖家（品牌）提供服务。
* ++达人合作伙伴++ （前身为 CAP）
   * 达人合作伙伴的主要功能是为 TikTok Shop 生态系统中的达人提供服务和支持孵化。
* ++达人匹配++**++ ++**++工具++ （前身为 TAP）
   * 代理机构合作伙伴利用我们的 TikTok Shop Partner Center 运行合作伙伴活动，帮助执行和加速卖家与达人之间的匹配，提供增量机会并推动增长。


# **TSP 分级规则**
## **TSP 等级**
TSP 将分为 5 个等级，从 S1 到 S5，对应：
**S1 TSP->S2 铜牌 TSP->S3 银牌 TSP->S4 金牌 TSP->S5 铂金 TSP**
合作伙伴的评级越高，其综合推广能力越强。
## **TSP 等级计算规则**
### **主要评估指标**
|  | **GMV - 70%** |  **加分 - 30%** |
| --- | --- | --- |
| 达人匹配 | TAP GMV | * TSP 服务多样性和卖家/达人增长能力的加分 |
| 达人服务 | CAP 直播 GMV |  |
| 卖家服务 | TSP 绑定 SKM 卖家 GMV |  |

* **GMV 计算方法**

**示例：**
一个 TSP 上月的 DAGMV 为：
TAP GMV：10k
达人服务 GMV：15k
卖家服务 GMV：20k
**排名中的总 GMV 计算为：**
++10k+15k+20k=45k++

# **不同 TSP 等级的权益**

* 权益从 S1 TSP 开始，S1 的要求是完成入驻后的培训并拥有 GMV。
* 平台根据合作伙伴的等级授予不同的权益，并根据权益推出计划及时调整。
* 不同等级的 TSP 可享受的权益包括但不限于：荣誉奖项访问、账号/店铺保护和申诉、直播支持、专属活动特权、运营支持等。

# **TSP 等级更新时间和公告机制**
## **更新时间**

* TSP 等级将在每月 3 日至 5 日更新，根据合作伙伴上月的绩效数据计算。
* 等级结果更新可能存在延迟，实际更新以产品内通知为准。
* 等级结果由系统根据多项绩效指标自动计算。也可能根据代理机构对卖家/达人的实际服务情况进行部分人工调整。目前不支持申诉。

# **TSP 治理**
## 卖家和达人服务通用规则

* 在代理机构合作期间，电商交易和内容中出现严重违规行为，包括但不限于未经授权的直播/录播/虚假订单/非法交易等，将导致 TSP 被平台终止。

## 卖家服务：
### 卖家绑定

* 入驻后，超过 3 个月未绑定卖家的代理机构将收到警告邮件。
* 入驻后，超过 6 个月未绑定卖家的代理机构将被移除。

### 客户投诉

* 一个月内收到超过 3 次客户投诉的代理机构将收到警告邮件。
* 发出正式警告后未改善，并连续再收到 5 次投诉，合作关系将被终止。

## 达人服务：

* 监控：定期监控代理机构的政策违规行为（如盗版或低质量内容）。
* 警告：如果发现风险，代理机构可能会收到警告并进入 **7 天观察期** 以修复问题。
* 执行：如果未改善或再次违规，可能会采取措施，包括 **移除合作关系。**
* 申诉：代理机构可以提交申诉，将在 **48 小时内** 审核。

#### ++*TSP 被移除后会发生什么++

1. 通用规则：
* 资质移除：移除特定国家的资质不可逆。只能添加其他国家的资质；
* 无法添加新的服务类目；
* 在已启用类目下已发布的服务将被下架；
* TTSPC 中相应的服务类目菜单将消失；
* 合作伙伴将从排名列表中移除。
2. 达人服务特定：
* 合作伙伴将自动与之前关联的达人解绑。
3. 卖家服务特定：
* 在被移除资质下发布的服务将标记为已下架；
* 服务订阅将被取消。
