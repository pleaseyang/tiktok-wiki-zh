# 搜索 Sample 申请履约

# Path: /affiliate_seller/202409/sample_applications/{application_id}/fulfillments/search
# Method: [POST]
# 功能描述
此 API 用于搜索 sample 申请的履约状态。您可以查看 sample 订单的物流和履约信息。
