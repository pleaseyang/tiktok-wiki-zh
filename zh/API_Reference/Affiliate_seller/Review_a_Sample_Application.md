# 审核 Sample 申请

# 路径：/affiliate_seller/202507/sample_applications/{application_id}/review
# 方法：[POST]
# 功能描述
此 API 用于审核达人提交的 sample 申请。您可以批准或拒绝申请。

| 字段 <!-- width:110px --> | 类型 <!-- width:90px --> | 必填 <!-- width:90px --> | 示例 <!-- width:254px --> | 描述 <!-- width:254px --> |
| --- | --- | --- | --- | --- |
| review_result | string | Y | APPROVE | 对 sample 申请采取的审核操作。可能的值： |

* APPROVE: 批准样品申请。
* REJECT: 拒绝样品申请。 |
   reject_reason |string |N |NOT_MATCH |卖家拒绝达人 sample 申请的原因。 The possible enumerated values are:
* NOT_MATCH: 该达人不符合卖家的协作要求。
* OFFLINE: 商品已下架。
* OUT_OF_STOCK: 商品暂时缺货。
* OTHER: 上述类目未涵盖的任何其他原因。
   当 review_result 设置为 REJECT 时必填
   此字段允许卖家指定拒绝样品申请的原因，使达人清楚了解拒绝缘由。 |
