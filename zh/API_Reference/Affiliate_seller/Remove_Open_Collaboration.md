# 移除 Open Collaboration

# Path: /affiliate_seller/202409/open_collaborations/products/{product_id}
# Method: [DELETE]
# 功能描述
此 API 用于移除 open collaboration。移除后，所有关联的 creator 将无法继续推广该产品。
