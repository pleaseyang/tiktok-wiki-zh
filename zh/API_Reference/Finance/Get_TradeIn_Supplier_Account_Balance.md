# 获取 TradeIn 供应商账户余额

# 路径：/finance/202609/account_balances
# 方法：[GET]
# 功能描述
检索当前授权的 TradeIn 供应商的可用账户余额。
供应商身份从授权上下文中解析。调用方不能指定 supplier_id 或 party_id。
