# 发布 Affiliate Partner 活动

# 路径：/affiliate_partner/202405/campaigns/{campaign_id}/publish
# 方法：[POST]
# 功能描述
此 API 提供发布 Affiliate Partner 活动的功能。活动发布后将对卖家显示。
