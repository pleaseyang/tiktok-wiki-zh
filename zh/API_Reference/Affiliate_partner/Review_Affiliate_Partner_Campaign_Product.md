# 审核 Affiliate Partner 活动 Product

# 路径：/affiliate_partner/202405/campaigns/{campaign_id}/products/{product_id}/review
# 方法：[POST]
# 功能描述
TikTok Affiliate Partner 使用此 API 来批准或拒绝卖家提交到活动的商品。商品必须处于待审核状态。
