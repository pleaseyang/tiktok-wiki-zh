# 上传买家消息图片

# Path: /customer_service/202309/images/upload
# Method: [POST]
# 功能描述
您必须先使用此 API 上传图片，然后才能使用 [Send Message](650a58bbbace3e02b7556286) 将图片作为消息发送。
