# 搜索合规审核产品

# Path: /product/202601/compliance/auditing/research
# Method: [POST]
# 功能描述
Search live products and retrieve the product information needed by a compliance vendor to prepare a compliance testing report. The selection behavior is:

* If `product_ids` is non-empty, the operation retrieves those known products. This branch takes precedence; seller, product-title, category, and brand filters and pagination are not used to select products.
* Otherwise, the operation performs a shop search and requires `seller_id`, `seller_name`, or both. When both shop identifiers are provided, their matching sellers are combined. You can further filter this search by product title, category IDs, and brand IDs and paginate the results.
