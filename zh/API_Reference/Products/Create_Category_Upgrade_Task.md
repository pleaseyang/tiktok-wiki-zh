# 创建分类升级任务

# 路径：/product/202407/products/category_upgrade_task
# 方法：[POST]
# 功能描述
创建一个任务，将状态为 `ACTIVATE` 的在售商品从 3 级类目树升级到 7 级类目树。
任务最长运行 2 小时，具体取决于商品数量。如果 2 小时后升级仍未完成，请再次调用该接口。要查明哪些商品的类目尚未升级，请调用 [Search Product API](https://partner.tiktokshop.com/docv2/page/65854ffb8f559302d8a6acda) 并将 "category_version" 设为 "v1"。
**注意**: 商品上架后必须等待至少 24 小时才能成功升级其类目。如果在新商品上架当天调用此接口，系统将无法检测到该商品。
