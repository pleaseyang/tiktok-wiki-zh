# 上传产品文件

# Path: /product/202309/files/upload
# Method: [POST]
# 功能描述
将非图片文件（如 PDF 或视频）上传到 TikTok Shop。
当您需要为产品添加视频以改善购物体验，或提交认证或报告以满足 TikTok Shop 上架受限产品的要求时，使用此 API。
**Note**: Retain the file ID from the response and pass it when creating or editing a product to associate the file with the product.

**Note**:

* Supported formats: PDF, MP4, MOV, MKV, WMV, WEBM, AVI, 3GP, FLV, MPEG
* Zero-byte files are rejected.
* Max PDF size: 20 MB
* Max video size: 100 MB
* Video aspect ratio: 9:16 to 16:9

**Recommendations for product videos**:

* Aspect ratio: 1:1
* Resolution: HD 720p or higher
* Duration: 20 - 60 seconds |
   name |string |Y |SNI.pdf |文件名称，包括文件扩展名 (e.g. `certification.pdf`)

**Note**:

* Do not use additional periods, except the one preceding the file extension.
* Do not begin the name with symbols.
* Do not include spaces. |
