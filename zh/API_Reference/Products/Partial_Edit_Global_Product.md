# 部分编辑全球产品

# Path: /product/202509/global_products/{global_product_id}/partial_edit
# Method: [PUT]
# 功能描述
Partially update an existing global product. Only the fields included in the request are considered for update. If the global product is linked to local products, applicable changes are also synchronized to those markets; check `publish_results` for each market's synchronization result.
