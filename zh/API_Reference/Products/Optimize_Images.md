# 优化图片

# 路径：/product/202404/images/optimize
# 方法：[POST]
# 功能描述
通过将背景改为白色来优化 TikTok Shop 中使用的图片。
这对于商品图片库中展示的图片尤其有用，因为它能提升商品的可见性。
**注意**：

* 待优化的图片必须先通过 [Upload Product Image API](https://partner.tiktokshop.com/docv2/page/6509df95defece02be598a22) 上传到 TikTok Shop。你将无法优化任何非 TikTok Shop 托管的图片。
* 此前已优化过的图片不会再次处理。
* 优化以异步方式处理，通常在几秒内完成。如果不存在已存储的优化结果，`optimize_status` 为 `PROCESSING`，表示优化正在进行中。如果已存在存储的最终结果，API 可能会立即返回该结果。当 `optimize_status` 为 `PROCESSING` 时，请在几秒后再次调用 API 以获取最终优化状态。
