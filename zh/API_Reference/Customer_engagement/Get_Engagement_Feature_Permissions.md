# 获取 Engagement 功能权限

# Path: /customer_engagement/202502/permissions
# Method: [GET]
# 功能描述
获取店铺对 customer engagement 功能的授权状态。

# 响应参数
| 属性 <!-- width:110px --> | 类型 <!-- width:90px --> | 示例 <!-- width:289px --> | 属性描述 <!-- width:289px --> |
| --- | --- | --- | --- |
| code | int | 0 | API 响应中返回的成功或失败状态码。 |
| message | string | Success | API 响应中返回的成功或失败消息。失败原因将在消息中描述。 |
| request_id | string | 202203070749000101890810281E8C70B7 | 请求日志 |
| data | object |  | 具体返回信息 |
| ^features | []object |  | 具有访问控制的 customer engagement 功能列表。 |
| ^^name | string | CUSTOM_MSG | 功能名称。 |
| 可能的值： |  |  |  |

* `FUNDAMENTAL`：使用任何 customer engagement API 或功能的能力。这是所有其他 customer engagement 功能的前提条件。
* `CUSTOM_MSG`：定义和发送自定义消息的能力。 |
   ^^is_authorized |bool |true |表示店铺是否有权限使用此功能的标志。
   可能的值：
* `true`：已授权使用此功能。
* `false`：未授权使用此功能。 |
