# 获取 FBT Merchant MCF 状态

# 路径：/fbt/202601/merchants/mcf_status
# 方法：[GET]
# 功能描述
检查卖家是否已入驻 Fulfilled by TikTok（FBT）并注册了多渠道履约（MCF）。此 API 目前仅支持美国卖家。如果两个条件都满足，`mcf_status.is_mcf` 为 `1`（已激活）。
