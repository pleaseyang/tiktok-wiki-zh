# 获取 FBT Merchant 已入驻区域

# 路径：/fbt/202409/merchants/onboarded_regions
# 方法：[GET]
# 功能描述
此 API 用于验证卖家是否已注册为 Fulfilled by TikTok（FBT）卖家。如果卖家已入驻，此 API 将返回该卖家在 FBT 系统中授权经营的区域。
