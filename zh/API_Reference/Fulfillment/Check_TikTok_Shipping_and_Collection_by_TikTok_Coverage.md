# 检查 TikTok Shipping 和 Collection by TikTok 覆盖范围

# 路径：/fulfillment/202508/tts_tracking_validation
# 方法：[GET]
# 功能描述
允许卖家或仓库验证 tracking 号码是否被 TikTok Shipping (TTS) 或 Collection by TikTok (CBT) 覆盖。
仅在**美国市场**可用。
