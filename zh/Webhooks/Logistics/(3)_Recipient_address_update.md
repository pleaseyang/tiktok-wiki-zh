# (3) 收件人地址更新

# 1. 触发场景
当订单收件人的地址更新时，会触发此**收件人地址更新** webhook。
# 2. 数据业务参数
| **参数名称** | **示例** | **描述** |
| --- | --- | --- |
| order_id | 1X2X3X4X5 | TikTok Shop 订单的标识符 |
| update_time | 1627587600 | 收件人地址更新的时间，以 Unix 时间戳（秒）表示。 |
## 事件示例
```json
{
    "type":3,
    "shop_id":"7494049642642441621",
    "timestamp":1644412885,
    "data":{
        "order_id":"576486316948490001",
        "update_time":1644412885
    }
}
```
