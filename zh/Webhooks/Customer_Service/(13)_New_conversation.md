# (13) 新会话

# 1. 触发场景
当客服人员加入或离开会话时，会触发此**新会话** webhook。
建议在收到此事件时刷新会话列表。
# 2. 数据业务参数
| **参数名称** | **数据类型** | **示例** | **描述** |
| --- | --- | --- | --- |
| conversation_id | string | 576486316948490001 | 会话的标识符 |
| create_time | int | 1627587506 | 会话创建时间，以 Unix 时间戳（秒）表示。 |
## 事件示例
```JSON
{
  "type": 13,
  "tts_notification_id": "7327112393057371910",
  "shop_id": "7494049642642441621",
  "timestamp": 1644412885,
  "data": {    
    "conversation_id": "576486316948490001",
    "create_time": 1627587506
  }
}
```
