# TikTok Shop 应用评分与分级政策
## 背景与定义
我们推出 TikTok Shop 应用评分与分级体系，以支持开发者在 TikTok Shop 生态系统中的长期增长。本政策说明应用评分的计算方式、分级分配方式以及各分级的权益，帮助您使应用与平台期望保持一致。
### 术语表
| **术语** | **定义** |
| --- | --- |
| App Store | TikTok Shop 卖家发现和安装应用的应用市场。 |
| 开发者 | 使用 TikTok Shop 开放平台能力构建和维护应用的个人或组织。 |
| API | 应用编程接口。一组规则和协议，使应用能够安全地访问 TikTok Shop 开放平台的能力。 |
| SLA | 服务等级协议。在此评分体系中，SLA 指集成及时性、稳定性和支持响应性的服务标准。 |
| TTSPC | TikTok Shop Partner Center。合作伙伴和开发者的协作工作区和管理仪表板。 |
| 类目 | 开发者根据应用的功能、服务和卖家使用场景在 TTSPC 中选择的应用类目。 |
| CSAT | 客户满意度评分 |

### 评估周期与调整
应用评分与分级体系是动态的，持续改进。

* **试点国家**：美国
* **试点类目：** 达人合作、可购物内容、ERP、客户支持、客户评价、连接器、多渠道管理、订单管理(OMS/WMS)、物流
* **定期刷新与复核**：我们按 **季度** 重新计算综合应用评分和分级。您的应用分级可能会根据您的表现和同类目中其他应用的表现而变化。
* **政策变更通知**：如果我们实质性变更评分维度、公式或分级规则，我们将提前通过官方渠道（如 TTSPC 站内信或邮件）通知您，以便您有时间审查和调整。

## 应用分级与权益
> 基于综合应用评分，应用被分为四个等级，从高到低依次为：**金牌、银牌、铜牌和基础**。应用在所属类目中的排名决定其分级和权益。

### 定义

* **金牌服务商：** 每个类目中评分最高的两个应用被指定为金牌服务商。
* **银牌服务商：** 每个类目中评分第三和第四的应用被指定为银牌服务商。
* **铜牌服务商：** 每个类目中评分第五到第七的应用被指定为铜牌服务商。在应用数量较少的类目中，铜牌服务商可能少于三个。
* **基础服务商：** 所有未归类为金牌、银牌或铜牌的其他应用。

根据类目的实际情况，金牌/银牌/铜牌服务商的数量可能略有浮动。

### 取消徽章资格的情形与规则
如果金牌、银牌或铜牌开发者涉及以下任何情形（包括但不限于），TikTok Shop 保留根据情节严重程度取消或调整其当前金牌、银牌或铜牌资格的权利。


* **政策与合规**：应用或其关联实体存在明显违反 TikTok Shop 平台政策、开发者指南或适用法律法规的行为。平台可相应调整开发者的分级状态。
* **评分与口碑操纵**：通过诱导、胁迫、虚假交易或组织/纵容虚假评价等方式不当影响评分和评论，严重损害评分体系的公平性。
* **安全与隐私**：发生严重安全漏洞或数据泄露，或未能按要求妥善保护商家和用户数据，导致商家或平台面临重大风险。
* **稳定性与事故**：频繁或严重的应用故障影响大量商家的正常运营，且整改不及时或整改效果持续不达标。
* **对接与能力**：长期未能对接或维护关键 API 或核心能力，导致核心功能缺失、与平台能力明显脱节或用户体验持续低于平台基线。
* **投诉与争议**：经核实的严重商家投诉长期未解决，或应用存在系统性问题导致广泛的负面商家体验影响。
* **侵权与合约违约**：存在知识产权或其他合法权益的重大侵权风险，或实质性违反与平台或商家的合约义务。

## 常见问题解答

1. **如何提升我的应用评分？**

通过优化应用列表、参与 TikTok Shop 营销活动以及与卖家合作进行教育和推广来增加应用的安装量。
关注技术稳定性和服务质量，如提高 API 成功率、减少故障和服务中断。及时对接平台发布的关键 API 和推荐功能，确保应用功能完整且易于卖家使用。
在符合平台政策的前提下，您可以通过应用内提示和持续沟通鼓励卖家留下真实、有建设性的评论，逐步建立更好的口碑。

2. **我的应用评分会直接影响其在 App Store 中的搜索排名吗？**

应用评分是平台用于搜索和推荐的多个信号之一。它不是唯一或决定性的排名因素。排名还考虑类目适配度、与卖家需求的相关性、整体质量和合规性。更高的评分通常会提升曝光度，但不保证特定位置。

3. **在哪里可以查看我的应用评分和详细诊断？**

应用评分和智能优化建议功能预计将于 2026 年 7 月中下旬在 TTSPC（TikTok Shop Partner Center）上线。请持续关注更新。同时，TikTok Shop 将定期发布分级排名和榜单，帮助您了解整体表现和相对位置。

4. **如果收到负面评价怎么办？平台会帮助删除吗？**

平台通常不会删除真实且符合政策的评论。我们鼓励您通过持续优化产品和服务来提升长期口碑。如果您怀疑某条评论是恶意的、欺诈的或以其他方式违反平台规则，您可以在 TTSPC 中提交工单。平台将审核该情况并决定是否需要采取行动。

5. **卖家可以编辑或删除自己的评论吗？**

在政策允许范围内，卖家可以删除已提交的评论。评论删除后，相关评分计算将更新，该评论不再纳入后续评估。开发者和合作伙伴不得代表卖家修改评论内容，也不得不当影响评论的创建或删除。

6. **评分数据多久更新一次？**

评分数据按季度更新和发布。卖家 CSAT 评分在卖家提交评分时实时更新。如果我们显著调整评分模型或其指标，我们将提前通过官方渠道通知您。

7. **如果对分级排名有异议，如何反馈？**

如果您对评分或分级有疑问，您可以通过 TTSPC 或现有的运营支持渠道提交反馈。请尽可能提供相关数据或案例。平台将按照标准流程审核您的请求，并在适当时调整结果或提供额外说明。所有评分和分级都是基于历史数据的定期评估，不代表对未来表现的保证。
## 免责声明与政策更新
TikTok Shop 应用评分与分级体系旨在客观、公正地评估应用的综合价值。为确保公平性和数据安全，TikTok Shop 不公开任何指标的内部阈值、权重或自动化模型。所有评分结果和分级状态仅以官方产品（如 App Store 和 TTSPC）中的展示为准。
如果我们对评分模型或相关政策进行重大变更，我们将提前通过开发者公告和官方邮件等渠道通知，以便您有时间了解变更并相应调整应用。
