# 卖家 API 概述


# 背景
使用卖家 API 获取卖家的活跃店铺或检查卖家是否有权限管理全球商品。我们的 API 帮助销售合作伙伴扩展服务，并大规模发展卖家在 TikTok Shop 上的业务。
此 API 目前通常被全球卖家用于检查店铺是否具备列出全球商品的能力。
卖家 API 帮助您以编程方式获取活跃店铺列表，并查询您是否有权限列出全球商品。
# 重要概念

* 卖家（对象）：在 TikTok Shop 平台中，卖家对象代表一个在平台上提供产品或服务进行销售的卖家或商户实体或账户。它通常包含与卖家身份、档案和设置相关的信息。

* **店铺状态**

# TikTok Shop 市场政策
作为市场平台，TikTok Shop 对卖家施加某些政策，以惠及买家和卖家双方。

* 我们支持全球卖家为每个目标销售国家开设 1 家店铺。
* 对于本地卖家，由于目标销售地只能在本地销售，因此一个卖家只能开设和经营 1 家本地店铺。
*  每个卖家都有一个由平台生成的唯一店铺代码和卖家 ID。店铺代码和 ID 一旦创建便无法修改。
* 每个卖家都需要完成注册并提交入驻信息，经入驻审核批准后，卖家即可在 TikTok Shop 开始经营，这意味着店铺状态为活跃。


# 常见问题

* 卖家有哪些不同类型？
   * **本地卖家**：在其注册企业所在国家/地区内销售产品的卖家，不涉及进出口贸易。
   *  **全球卖家**：向其注册企业所在国家/地区以外的多个国家销售产品的卖家。他们从事跨境贸易活动，包括结算和物流。
   *  **欧盟内部卖家**：其企业注册在一个欧盟国家，并向其他欧盟国家的客户销售产品的卖家。



* 什么是全球商品？
   * 全球商品仅适用于**全球卖家**和**欧盟内部卖家**，本地卖家无法使用此功能。为了提高多店铺商品管理的效率，卖家可以通过此全球商品集中管理商品信息，并将更改应用到多个市场的商品。上传全球商品后，卖家只需一键即可将其发布到多个市场的店铺。
