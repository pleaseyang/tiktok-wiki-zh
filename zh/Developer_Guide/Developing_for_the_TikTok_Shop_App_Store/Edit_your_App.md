# 编辑你的应用

# 编辑 public 应用列表
本指南说明如何在 TikTok Shop Partner Center 中更新现有 **public 应用** 的 App and Service Store 列表，包括在哪里编辑列表、哪些字段影响商店页面，以及提交变更审查后会发生什么。
本页面仅适用于 **public 应用列表编辑**。Custom 应用不在 App and Service Store 中公开上架，因此此处描述的列表部分不适用于大多数 custom 应用。要编辑 custom 应用的基本配置，请使用 **Partner Center > App & Service > 选择应用**。要了解 public 和 custom 应用之间的区别，请参阅[创建你的应用](https://partner.tiktokshop.com/docv2/page/create-your-app)和[应用上线概述](https://partner.tiktokshop.com/docv2/page/app-launch-overview)。
# 编辑之前
在创建新列表草稿之前，请确认以下事项：
| 检查项 | 重要性 |
| --- | --- |
| 你正在编辑正确的 public 应用 | 列表变更影响批准后卖家在 App and Service Store 中看到的内容。 |
| 应用有现有的列表草稿或已发布列表 | 本指南涵盖编辑现有列表，而非首次 public 应用列表提交。首次列表请参阅[发布和上架 public 应用](https://partner.tiktokshop.com/docv2/page/publish-and-list-public-app)。 |
| 品牌资产和截图已就绪 | Logo、媒体和截图必须符合 Partner Center 中显示的文件类型、大小和尺寸要求。 |
| 支持和法律 URL 为公开可访问 | 不要在 public 应用列表中使用内部 Lark、飞书、Google Drive、内网或需要权限的链接。 |
| 定价信息已确认 | 如果列表显示价格标签或定价详情，请在提交前准备内容。请参阅[应用价格信息](https://partner.tiktokshop.com/docv2/page/app-price-information)。 |
# 打开列表草稿
使用以下入口路径作为编辑 public 应用列表的标准路径：
```Plain Text
Partner Center
  -> App & Service
  -> 选择 public 应用
  -> 更多选项 (...)
  -> Listing Review
  -> Edit Draft
```

某些相关页面可能将此区域称为 **Publish 旁边的 Edit** 或 **service listing review**。使用打开所选 public 应用的 **Listing Review** 草稿编辑器的入口。
编辑列表的步骤：

1. 登录应用市场对应的 Partner Center。
2. 从导航面板打开 **App & Service**。
3. 选择要更新的 public 应用。
4. 打开更多选项菜单（显示为 **...**），选择 **Listing Review**。
5. 选择 **Edit Draft**。
6. 更新列表字段。
7. 选择 **Save** 保存草稿进度。
8. 列表就绪后，选择 **Publish Changes**。

草稿变更在列表审查批准之前不会在 App and Service Store 中可见。
# 列表字段
列表编辑器控制应用在 App and Service Store 中的展示方式。使用 Partner Center 中显示的字段要求作为权威来源，因为要求可能因市场、语言、类别或媒体类型而异。
| 列表区域 | 显示位置 | 需要准备的内容 |
| --- | --- | --- |
| 应用名称 | 商店列表标题、搜索结果和应用详情页面 | 使用应用的公共品牌或产品名称。保持与你的支持站点、隐私声明和面向卖家的材料一致。 |
| Logo | 商店卡片和应用详情页面 | 上传清晰的方形 logo。常见的 public 列表限制包括 **1:1 宽高比** 和 **最大 10 MB**。使用 Partner Center 验证当前接受的文件类型和尺寸。 |
| 简短描述 | 商店卡片、搜索结果和应用详情页面顶部 | 用一句简短的话概括应用对卖家的价值。常见的 public 列表限制包括 **最多 200 个字符**。 |
| 精选媒体和图片 | 应用详情页面媒体画廊 | 使用展示面向卖家产品体验的截图或媒体。不要上传内部管理截图、机密仪表板、不可读的 UI 截图或占位图片。遵循 Partner Center 中显示的大小、文件类型和尺寸要求。 |
| 核心优势 | 应用详情页面优势部分 | 描述具体的卖家成果，如更快的订单处理、库存同步或简化的报告。避免无依据的性能声明。 |
| 详细描述 | 应用详情页面正文 | 解释应用的主要使用场景、支持的市场、前提条件、操作限制以及安装后需要的任何卖家操作。 |
| 集成 | 应用详情页面和商店筛选器（适用时） | 列出应用连接的外部系统、商务平台、ERP、OMS、WMS、3PL、feed 工具或其他平台。对于 Connector 和 Multi-Channel 应用，此信息可能将应用与相关的 **Popular platforms** 筛选器关联。 |
| 联系信息 | 应用详情页面的支持区域 | 提供受监控的支持电子邮件、支持站点或联系表单。避免使用可能变为不活跃的个人联系方式。 |
| 额外资源 | 应用详情页面资源链接 | 链接到公共帮助中心页面、入门指南、条款、隐私声明或 API 设置说明。不要链接到内部飞书/Lark 文档或需要权限的文件。 |
| 价格标签和价格信息 | 应用详情页面的定价区域 | 选择与面向卖家定价模型匹配的价格标签，并提供准确的定价详情。请参阅[应用价格信息](https://partner.tiktokshop.com/docv2/page/app-price-information)。 |
# 公开链接要求
应用列表中的所有链接必须可供外部卖家和 TikTok Shop 审查员在没有内部员工权限的情况下访问。
不要使用：

* 公司内部 Lark 或飞书文档链接。
* 内部 wiki、内网或云盘链接。
* 需要审查员访问权限审批的私有文件。
* 可能过期的临时文件分享链接。

请改用公开的产品、支持、文档、隐私、条款和定价页面。有关定价指南，请链接到[应用价格信息](https://partner.tiktokshop.com/docv2/page/app-price-information)，而非内部文档。
# 提交变更进行审查
当你选择 **Publish Changes** 时，Partner Center 创建一个列表审查请求。
| 审查状态 | 含义 | 操作 |
| --- | --- | --- |
| Draft | 变更已保存但未提交。 | 继续编辑或在就绪时选择 **Publish Changes**。 |
| In review | TikTok Shop 正在审查列表更新。 | 在 **Listing Review** 中监控状态。在请求审查中时，不要假设草稿变更已上线。 |
| Approved | 列表更新通过审查。 | 批准的列表变更在 App and Service Store 中可见。现有应用授权不会因列表文本或媒体更新而改变。 |
| Rejected | 列表更新未通过审查。 | 打开审查详情，阅读拒绝原因，更新草稿，保存并再次选择 **Publish Changes**。 |
审查时间因市场、应用类别、语言、提交质量以及变更是否同时触发应用审查、合规审查或法律审查而异。使用 Partner Center 中显示的状态和任何 SLA 作为权威来源。列表审查请预留 7-10 个工作日，如果更新依赖于更广泛的应用或合规审查，请预留更长时间。
有关审查工作流、审查材料和拒绝处理，请参阅[应用审查流程](https://partner.tiktokshop.com/docv2/page/app-review-process)。如果拒绝原因不明确，请提交 Partner Center 支持工单，附上 app key、service ID、目标市场、审查状态、拒绝消息和截图。请参阅[如何联系支持](https://partner.tiktokshop.com/docv2/page/how-to-contact-support)。
# 列表编辑如何影响 App and Service Store
使用此映射检查每次编辑是否改变了 public 列表的预期部分：
| 编辑 | 商店效果 |
| --- | --- |
| 应用名称、logo 和简短描述 | 批准后更新商店卡片、搜索结果外观和详情页面顶部。 |
| 精选媒体和图片 | 批准后更新详情页面上的媒体画廊。 |
| 核心优势 | 更新向评估应用的卖家显示的优势摘要。 |
| 详细描述 | 更新应用详情页面正文内容。 |
| 集成 | 更新详情页面显示的集成信息，并可能影响 Connector 或 Multi-Channel 应用的相关平台筛选器。 |
| 联系信息和额外资源 | 更新卖家支持和入门链接。 |
| 价格标签和价格信息 | 更新向卖家展示定价的方式，具体取决于 Partner Center 中可用的选项。 |
