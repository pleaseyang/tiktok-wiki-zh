# 通过合作伙伴助手提交工单
如果您是已注册的 ISV（应用开发者），可以通过 **合作伙伴助手**（合作伙伴 Assistant）获取答案并提交支持工单，这是 TikTok Shop 合作伙伴中心内置的 AI 问答助手。请先用通俗的语言描述您的问题——您可能会立即获得答案。如果答案未能解决您的问题，只需点击一下即可**提交工单**。
**注意：** 之前的独立工单入口已停用。每个新工单现在都需要先在合作伙伴助手中进行至少一轮问答。您仍然可以在**支持工单**页面查看和管理现有工单。

1. 通过以下任一方式打开合作伙伴助手：点击任意合作伙伴中心页面上的**浮动按钮**（将鼠标悬停在上面可看到**向合作伙伴助手寻求帮助**），或点击顶部导航栏中的**帮助**并选择**询问合作伙伴助手**。合作伙伴助手将在页面右侧以滑出式抽屉的形式打开：
<div style="text-align: center"><img src="https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/eda1d66ce9e341da834b95ff6f5e65cf~tplv-k9wyc2ijk0-image.image" width="800px" /></div>

2. 在输入框中描述您的问题。请包含具体信息，例如 API 名称、错误码或 Request ID，以帮助合作伙伴助手提供更精确的回答。合作伙伴助手将以通俗的语言回复解释、相关文档链接和建议的下一步操作：
<div style="text-align: center"><img src="https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/9f84f1ec603645c391e666de8a800a54~tplv-k9wyc2ijk0-image.image" width="800px" /></div>

3. 如果回复未能完全解决您的问题，请点击回复下方工具栏中的**提交工单**：
<div style="text-align: center"><img src="https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/2a554d4ff9cb4c33aa18ff561f371d91~tplv-k9wyc2ijk0-image.image" width="800px" /></div>

**注意：** 即使合作伙伴助手暂时不可用，**提交工单**功能仍然可用，因此您始终可以联系我们的支持团队。

4. 填写工单详情：选择适当的问题类别，以便将您的工单转至相关联系人；提供工单标题和详细的问题描述，并附上任何相关的文件和文档。您的描述越详细，我们的支持团队就越能高效地为您提供及时的帮助。填写完成后，提交工单：
<div style="text-align: center"><img src="https://p16-arcosite-sg.ibyteimg.com/tos-alisg-i-k9wyc2ijk0-sg/bc409b65c9b943e595f9363865c97065~tplv-k9wyc2ijk0-image.image" width="800px" /></div>

5. 工单提交成功后，将显示确认信息：

# 工单响应时间
提交工单后，我们的支持团队将在 24 个工作小时内提供首次响应（通常会更快），以解答您的问题。我们的目标是在 48 个工作小时内完全解决您的问题。

* **首次响应：** 通常 < 24 个工作小时
* **问题解决：** 目标 < 48 个工作小时

请注意，这些是通用的响应时间指南，我们始终会尽力尽快满足您的需求。
