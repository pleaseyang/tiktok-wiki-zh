# 应用类别选指南

## 1. 概述（是什么为什么）
**应用类别**是您在 TikTok Shop 合作伙伴中心创建应用时必须选择的业务分类。它描述了您的应用程序旨在服务的主要业务场景。
选择正确的类别通常会影响：

* **可用的 API 范围**：您可以申请的默认 API 能力集因类别而异。
* **应用商店定位**：该类别帮助商家了解您的应用功能以及是否符合其需求。
* **目标用户匹配**：准确的类别有助于合适的商家更快地发现您的应用。

**目标受众：**

* 第三方 ISV（独立软件开发商）
* 卖家自建开发团队

**重要提示 — 此选择不可撤销**：一旦选择了应用类别，**无法通过任何渠道更改**。如果选择了错误的类别，您必须创建新的应用。请在创建应用前仔细确认。在创建应用时也会重申此限制。

## 3. 类别与 API 范围（快速参考）
应用类别决定了您在创建应用后可以申请的**默认 API 范围集**。部分敏感或受限范围可能需要额外审核或平台开通。请先根据业务定位选择类别，然后在应用创建页面上验证您所需的能力是否可用。
如果您所需的范围未列在您的类别下，并**不一定**意味着它不可用。请参考合作伙伴中心页面和实际审核结果。对于受限能力，请联系您的 TikTok Shop 客户经理或官方支持以确认开通条件。
## 4. 常见问题
### Q1. 我应该选择哪个类别？
**答：**选择最能代表您**主要业务场景**的类别：

* 我构建电商/ERP 集成 → **电商管理**
* 我构建物流/履约解决方案 → **物流与履约**
* 我构建营销/广告工具 → **营销**
* 我是为自己店铺开发的卖家 → **卖家自建开发者**
* 我提供全托管或跨市场集成服务 → **全球化卖家**

如果您的产品跨多个方向，请选择最能代表您**核心产品价值**的类别。
### Q2. 创建应用后可以更改类别吗？
**答：不可以。**一旦选定，类别将被锁定，**无法通过任何渠道更改**。如果选择了错误的类别，您必须创建新的应用。
### Q3. 类别是否决定了我可以申请哪些 API 范围？
**答：**是的。每个类别都有一套默认的可申请 API 范围。部分敏感或受限能力可能还需要额外审核或平台开通。
### Q4. **卖家自建开发者**和 ISV 类别有什么区别？
**答：**

* **卖家自建开发者**适用于**卖家自建团队** — — 仅**服务于自己店铺**的应用。
* **ISV/第三方类别**适用于**服务多个商家**并向外部卖家提供的应用。

### Q5. 我的类别中缺少我所需的部分范围 — — 是否意味着不可用？
**答：**不一定。类别范围覆盖可能随时间变化。如果您没有看到所需的范围，请与您的客户联系人或通过官方支持确认可用性。
### Q6. 选择错误的类别会影响我的审核吗？
**答：**是的。与实际业务不匹配的类别可能会**限制您可申请的 API 范围**，并可能影响应用审核和上架效率。
### Q7. 类别名称会随时间变化吗？
**答：**是的。随着产品的发展，类别可能会被**新增、合并或重命名**。请始终参考合作伙伴中心界面显示的最新选项。
### Q8. 我的产品覆盖商品管理、履约和分析 — — 应该选哪个？
**答：**选择**最核心、最稳定且最常用**的主要能力。如果您的主要价值主张是系统集成和运营编排，**电商管理**通常是最佳选择。
### Q9. 我的应用仅服务于我自己的店铺 — — 还需要选择面向 ISV 的类别吗？
**答：**通常不需要。如果您的应用仅**内部用于自己的店铺**，**卖家自建开发者**是更合适的选择。
### Q10. 什么样的应用适合全球化卖家？
**答：**专为**跨市场运营、全托管服务或综合端到端解决方案**设计的应用。
